## Zero-Copyleft Guarantee & Unprivileged Execution

- Zero-Copyleft Guarantee: All runtime code, vendored assets, and development dependencies are governed strictly by permissive, business-friendly open-source licenses (MIT, Apache-2.0, PSF-2.0). The codebase contains 0% copyleft (zero GPL, AGPL, or viral copyleft components).
- Unprivileged User-Mode Operation (RunAsInvoker): All skills, validation scripts, catalog generators, and tests execute purely within unprivileged user space. No administrative rights, root elevation, sudo, or UAC prompts are ever required.

## Governance & Runtime Invariants

ellmos-skills strictly enforces ten foundational governance and runtime invariants:
- INV-LOCAL-01: 100% Local-First & Zero Egress (Network & Privacy: pure Markdown and local Python scripts; zero telemetry and zero outbound network calls)
- INV-PRIVACY-02: Fail-Closed Privacy Boundary Gate (Data Protection: automated privacy gate rejects concrete user homes, host-scoped names, and token patterns)
- INV-UNPRIV-03: Non-Elevation & RunAsInvoker (Process Execution: all workflows execute strictly in unprivileged user space; root or admin elevation prohibited)
- INV-SCHEMA-04: Deterministic Frontmatter & Schema Integrity (Contract Compliance: YAML frontmatter strictly conforms to conventions and schema validation gates)
- INV-ISOLATION-05: Portable & Self-Contained Skill Anatomy (Modularity: skills package their own playbooks, references, and scripts without implicit host couplings)
- INV-PORTABLE-06: Multi-Agent Runtime Portability (Interoperability: compatible with Claude Code, Codex, AGY/Gemini, BACH, and local Ollama runtimes)
- INV-DISCOVERY-07: Public/Private Boundary Isolation (Boundary Hygiene: public catalog exposes only verified non-sensitive discovery fields)
- INV-PLATFORM-08: Multi-OS Parity & Platform Independence (Portability: Linux, Windows, macOS validated identically via multi-OS CI matrix on Python 3.10 to 3.13)
- INV-SYNC-09: Multi-Host Cloud Sync & Lock Resilience (Concurrency: hardened .gitignore and cooperative lock protocols prevent cloud sync races and data corruption)
- INV-SLA-10: 48h Security Response & Triage Commitment (Governance: formal response SLA: 48h initial acknowledgment, 5-day triage commitment via SECURITY.md)
