# ब्लेंडर का उपयोग (Deutsch)

## मूल नियम

कार्य के अनुसार ब्लेंडर के साथ तीन मोड में काम करें:

1. **GUI-मोड:** जब उपयोगकर्ता किसी एसेट को देखना, आंकना या मैन्युअल रूप से आगे संपादित करना चाहता हो, तब ब्लेंडर को दृश्यमान रूप से खोलें।
2. **Headless-मोड:** जब एक्सपोर्ट, रीइम्पोर्ट, बैच प्रसंस्करण या निर्धारक (deterministic) जाँच मांगी गई हो, तब `blender --background --python <script.py>` का उपयोग करें।
3. **MCP-मोड:** केवल तभी उपयोग करें जब कोई चल रहा Blender ऐडऑन जानबूझकर जुड़ा हो और लाइव दृश्य नियंत्रण आवश्यक हो। पहले सुरक्षा और लाइसेंस स्थिति जाँचें।

## मानक प्रवाह

1. लक्ष्य स्पष्ट करें: देखना, बनाना, परिवर्तित करना, अनुकूलित करना, रेंडर करना या सत्यापित करना।
2. मौजूदा फ़ाइलें पढ़ें: पहले मैनिफ़ेस्ट, README, एक्सपोर्ट फ़ॉर्मेट और मौजूदा जाँच परिणाम देखें।
3. ब्लेंडर पथ निर्धारित करें: PATH पर `blender`, परियोजना-विशिष्ट कॉन्फ़िगरेशन या उपयोगकर्ता पथ। सार्वजनिक प्रकाशन योग्य दस्तावेज़ों में स्थानीय निजी पथ न लिखें।
4. स्वचालन के लिए एक छोटी `bpy` स्क्रिप्ट का उपयोग करें, जो इनपुट, आउटपुट और त्रुटियों को स्पष्ट करे।
5. हर एक्सपोर्ट के बाद कम से कम एक रीइम्पोर्ट या लोड जाँच करें, उसके बाद ही परिणाम को उपयोगी माना जाए।
6. कलाकृतियों (artifacts) का संक्षिप्त दस्तावेज़ीकरण करें: स्रोत, एक्सपोर्ट फ़ॉर्मेट, टूल संस्करण, जाँच स्थिति और ज्ञात सीमाएँ।

## एक्सपोर्ट और जाँच नियम

- सामान्य वेब/पूर्वावलोकन उपयोग के लिए `.glb` को प्राथमिकता दें।
- गेम इंजन और DCC आदान-प्रदान के लिए, जब लक्ष्य वर्कफ़्लो को इसकी आवश्यकता हो, तो `.fbx` या `.obj/.mtl` भी प्रदान करें।
- राउंडट्रिप के लिए हमेशा जाँचें: फ़ाइल मौजूद है, खाली नहीं है, रीइम्पोर्ट हो सकती है, और अपेक्षित ऑब्जेक्ट/सामग्री नाम मौजूद हैं।
- बड़े एसेट्स के लिए मेट्रिक्स दर्ज करें: मेश संख्या, सामग्रियाँ, बाउंडिंग बॉक्स, फ़ाइल आकार और वैकल्पिक रूप से त्रिभुज (triangle) संख्या।
- महंगे Cycles या Full-HD रेंडर शुरू करने से पहले रेंडर जाँच के लिए छोटे पूर्वावलोकन रिज़ॉल्यूशन का उपयोग करें।

## सुरक्षा नियम

- `bpy` कोड फ़ाइल सिस्टम पहुँच वाला स्थानीय Python कोड है। केवल स्वयं लिखी गई या ऑडिट की गई स्क्रिप्ट चलाएँ।
- लाइसेंस और गोपनीयता जाँच के बिना बाहरी ब्लेंडर ऐडऑन, एसेट डाउनलोडर या टेलीमेट्री सर्वर सक्रिय न करें।
- किसी मनमाने `execute_python` टूल वाले MCP सर्वर के लिए पहले स्कोप, नेटवर्क, कार्य निर्देशिका और टाइमआउट सीमित करें।
- मार्केटप्लेस या बाहरी एसेट्स के लिए लाइसेंस अलग से जाँचें। तकनीकी रूप से लोड होना उपयोग अधिकारों का विकल्प नहीं है।

## GUI खोले बिना परिणाम जाँचें

एसेट्स के लिए एक तैयार बैकग्राउंड गेट उपलब्ध है, जो **चार रेंडर और मापने योग्य मेट्रिक्स** एक ही रन में देता है (रोटेशन, पिवट, तैरते हुए भाग):

```powershell
blender.exe --background --factory-startup `
  --python "<OneDrive>\.TOPICS\.ROBLOX\_tools\verify_asset_visual.py" -- `
  --fbx "<asset.fbx>" --out "<ordner>" --json
```

कोई GUI नहीं, कोई फ़ोकस आवश्यक नहीं। विवरण और सीमाएँ (जिनमें: MCP सर्वर `ellmos-blender-use` **रेंडर नहीं कर सकता**): `.ROBLOX\BLENDER_ASSET_CHANNELS.md`।
विस्तृत वर्कफ़्लो: कौशल `build-assets-with-blender`।
