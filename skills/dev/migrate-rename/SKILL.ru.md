# Переименование файлов с помощью файлов-оберток (Эволюционная миграция) (Русский)

> Позволяет переименовывать файлы БЕЗ жестких сбоев. Ссылки органично обновляются в процессе ежедневного использования.

---

## Принцип: Эволюционная миграция

```
ДО:                             ПОСЛЕ:
old_file.md                      new_file.md (переименован)
   |                                |
   +-- Ссылка A                     +-- old_file.md (обертка/wrapper)
   +-- Ссылка B                            |
   +-- Ссылка C                            +-- Таблица журнала
                                           +-- Инструкции
                                           +-- Ссылка на new_file.md
```

Когда кто-то обращается к старому пути:
1. Попадает на файл-обертку (wrapper)
2. Добавляет запись в журнал
3. Исправляет ссылку, которая привела его сюда
4. Переходит к фактическому файлу

---

## Пошаговое руководство

### 1. Переименовать файл

```bash
mv old_file.md new_file.md
```

### 2. Создать файл-обертку (wrapper)

Создайте `old_file.md` со следующим содержимым:

```markdown
# OLD_FILE.md - Перенаправлено (Русский)

**Статус:** Этот файл был переименован в `new_file.md`

---

## Журнал миграции

| Дата | Кто | Источник | Ссылка исправлена? |
|------|-----|----------|-------------------|
| ГГГГ-ММ-ДД | [Имя] | Начальная миграция | н/д (создана обертка) |

---

## Инструкции

1. **Оставьте запись в журнале** (в таблице выше)
2. **Проверьте источник**: Что направило вас сюда?
3. **Исправьте ссылку**: Измените `old_file.md` -> `new_file.md`
4. **Перейдите к целевому файлу**: [new_file.md](new_file.md)

---

**Целевой файл:** [new_file.md](new_file.md)
```

### 3. Немедленно исправить критические ссылки
- Файлы справки (основная документация)
- Ссылки в системных промптах
- Код CLI, непосредственно использующий этот путь

### 4. Постепенно мигрировать оставшиеся ссылки
Остальные ссылки автоматически исправляются в процессе использования.

---

## Когда использовать метод обертки?

**ДА — Обертка полезна:**
- Много потенциальных ссылок
- На файл ссылаются различные партнеры/инструменты
- Не является критическим системным файлом

**НЕТ — Изменить все напрямую:**
- Мало известных ссылок
- Критические системные файлы (конфигурация, схема БД)
- Пути, критичные к производительности

---

## Очистка

Примерно через 30 дней или когда в журнале не появляется новых записей:
1. Переместите файл-обертку в `_archive/deprecated/`
2. Или удалите полностью (если новых записей больше нет)
