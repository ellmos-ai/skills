# Bilingual-Doc-Sync — 保持并行语言版本同步 (中文)

## 概述与目的

双语管理的文档会逐渐发生偏差：主编辑的版本不断扩展，而另一版本则过时衰退——直到“翻译”仅名存实亡。本 Skill 将同步检查转化为具有关键前置预定的标准流程：**哪个语言版本为主导？** 如果没有主导语言规则，每次差异比较都会变成逐案决定，比对结果也无法复现。

## 流程

### 1. 确认现存版本

- 是否所有（两种或多种）语言版本均已具备？如果完全缺失某一版本 → **补齐**（对主导版本进行完整翻译，而非重新撰写）。
- 检查命名规范（例如 `DOCUMENT.md` + `DOCUMENT.en.md` 或 `_de`/`_en` 后缀），统一不一致的命名——良好的可查找性是实现同步的一半。

### 2. 明确主导语言（在每次同步前）

- 主导语言（Leitsprache）是指在内容上进行主要编辑的版本（学术论文通常为英文 EN，本地文档通常为母语）。发生冲突时以主导语言为准。
- **反向吸收例外：** 如果辅助版本在某些内容上有明确更好的处理（更清晰的表述、修正的错误），应将其**吸收**回主导版本——先进行反向吸收，然后再按常规进行同步。在吸收看似“更优美”的表达之前，必须先核实其专业准确性。

### 3. 检查并行性

先检查结构，再检查内容：

1. **大纲对比：** 将两个版本的章节/标题并排对比——缺失、新增或排序变更的章节属于明显的粗粒度偏差。
2. **匹配大纲的逐段抽查：** 论述、数据、引用、示例是否一致？特别容易发生偏差的地方包括：变更日志（Changelog）、表格、数值、参考文献/链接列表、最近编辑的章节。
3. **检查不可翻译的独立不变量：** 代码块、标识符、公式、路径在两个版本中必须**完全一致**（代码绝不翻译）。

### 4. 修复与解决

- 朝主导语言的方向消除偏差（或在完成反向吸收后进行）。
- 尊重目标语言的文字排版规范（标点符号使用规范、空格与排版约定）。
- 同步更新元数据：在**两个**版本中同时补齐版本号、日期字段、变更日志条目（变更日志本身是最常见的偏差发生点）。

### 5. 记录与归档

记录核查结果（哪些地方存在偏差、吸收了什么内容、反向吸收了什么内容）。
作为对文档库的定期巡检：结合轮换检查机制（`rotation-check`）——每次运行处理一个文档（或一对文档），利用 Register 保持记录。

## 扩展：扩展审计（是否需要支持更多语言？）

除了保持现有版本的同步外，语言维护还包括评估某个文档/项目是否值得支持**更多**语言：

1. **评估适宜性**而非盲目翻译：目标受众、国际通用性、应用商店/网站展示需求、内容的流动性。并非每个内部文档都需要英文；并非每个 App 都需要五种语言。
2. **检查技术准备情况：** 目标项目是否已在技术上支持多语言文件/并行版本（i18n 架构、命名规范）？如果否，**这**才是首要任务，而不是直接翻译。
3. **记录诊断结果，避免立即盲目批量翻译：** 将具体的翻译任务写入项目本地的 TODO 文件；“无需支持其他语言”是一个有效且应当记录的结果。
4. **补齐版本的质量检查（QA）：** 在自动生成的翻译被视为“已具备”之前，必须针对主导版本进行抽样检查（参考第 3 节）。

## 示例与用法

```text
任务：“检查论文的德语 (DE) 和英语 (EN) 版本是否同步。”

1. 现存版本：paper_en.tex (主导) + paper_de.tex 均存在。
2. 大纲对比：DE 缺失了最新的第 4.2 节（EN 最新修订版）；DE 在 3.1 节中包含一个更好的证明段落。
3. 反向吸收：3.1 的表述经专业核实 → 吸收回 EN。
4. 补齐同步：将 4.2 翻译为 DE；核对表 2 中的数据（DE 中为过时数值）；统一参考文献列表。
5. Register 记录：“paper-X | 2026-07-03 | de-en-sync | 修复 3 处偏差，1 处反向吸收 | 下次检查安排在 EN 再次修订后”。
```

## 红旗警告 (Red Flags)

| 错误想法 | 现实情况 |
| --- | --- |
| “我直接把差异部分重新翻译一遍” | 必须先确定主导语言并确认是否存在反向吸收——否则更好的解决方案会被覆盖掉。 |
| “大纲能对应上，所以就是同步的” | 数据、变更日志和引用链接最容易先发生偏差——必须深入抽样检查。 |
| “代码注释我也一起翻译了” | 代码块和标识符在两个版本中保持完全一致（英文）。 |
| “我一次性把所有文档全都同步完” | 每次运行只处理一对文档（结合轮换检查机制），以保持比对过程的可核查性。 |
