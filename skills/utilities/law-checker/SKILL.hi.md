# law-checker (Law-Checker) -- संदर्भ-skill

यह skill एक **हल्का संदर्भ (Wrapper)** है, जो स्वतंत्र, सार्वजनिक मॉड्यूल रिपॉज़िटरी
[`ellmos-ai/law-checker`](https://github.com/ellmos-ai/law-checker) (MIT लाइसेंस, सार्वजनिक) की ओर इंगित करता है। वास्तविक skill वहीं रहती है -- यह रिपॉज़िटरी केवल स्थापना को लिंक और दस्तावेज़ित करती है, ताकि मॉड्यूल केंद्रीय skill कैटलॉग के माध्यम से खोजा जा सके।

## मॉड्यूल क्या करता है

`law-checker` जर्मन कानून के लिए स्रोत-आधारित AI प्रारंभिक आकलन प्रदान करता है:

- **कानून रजिस्ट्री** (`config.json`): जोड़े जा सकने वाले कानून-संहिताएँ; प्रत्येक कानूनी कथन स्थानीय रूप से लोड किए गए, आधिकारिक मानक-पाठों से प्रमाणित होना चाहिए (अनुच्छेद/धारा, उपधारा, वाक्य, संक्षिप्त उद्धरण, स्रोत, पहुँच-तिथि)।
- **कानून-संहिता-अवतार एजेंट** (`agents/gesetzbuch.md`): एक सामान्य एजेंट, जो प्रत्येक पंजीकृत कानून के लिए "कानून के भीतर से" उत्तर देता है -- रजिस्ट्री में किसी भी कानून तक विस्तार योग्य।
- **अलग न्यायिक-निर्णय परत:** निर्णयों को केवल वेब-सत्यापन के बाद उद्धृत किया जाता है (न्यायालय, तिथि, मामला/केस संख्या (Aktenzeichen), जहाँ उपलब्ध हो ECLI)।
- **जोखिम और एस्केलेशन वर्कफ़्लो:** जोखिम-संकेतक (ट्रैफ़िक लाइट) के साथ राय-प्रारूप, समय-सीमा अनुशासन और वकील-विशेषज्ञता मैट्रिक्स।

## सीमाएँ (महत्वपूर्ण)

- **AI-सहायता प्राप्त प्रारंभिक अभिमुखीकरण, व्यक्तिगत कानूनी सलाह का विकल्प नहीं और न ही वकालत का लाइसेंस।**
- कोई लॉ-फ़र्म/वकालत-कार्यालय का संचालन नहीं, कोई होस्ट की गई कानूनी सेवा नहीं, कोई समय-सीमा कैलेंडर नहीं।
- वास्तविक कानूनी डाक (चेतावनी-पत्र, आदेश, मुकदमा, समय-सीमा) के मामले में: मूल दस्तावेज़ सुरक्षित रखें, समय-सीमा नोट करें, योग्य कानूनी परामर्श लें -- मामले को स्वचालित न करें।

## स्थापना (सामान्य, स्थानीय ठोस पथों के बिना)

1. मॉड्यूल क्लोन करें:
   ```bash
   git clone https://github.com/ellmos-ai/law-checker.git <klon-pfad>
   ```
2. `<klon-pfad>/SKILL.md` को अपने skill वातावरण में लें (जैसे `~/.claude/skills/law-checker/` या उपयोग किए जा रहे एजेंट-रनटाइम का समकक्ष)।
3. अपनाई गई `SKILL.md` में, या उससे संबंधित संदर्भों में, मॉड्यूल-पथ `<klon-pfad>` पर सेट करें -- कोई वास्तविक स्थानीय पथ या होस्टनाम संस्करण-नियंत्रित skill वातावरण में कमिट न करें।
4. कानून रजिस्ट्री लोड करें: `python <klon-pfad>/_tools/gesetze_fetch.py` (कॉन्फ़िगर किए गए आधिकारिक मानक-पाठ लाता है; मानक-पाठ स्वयं जानबूझकर रिपॉज़िटरी में नहीं हैं, ताकि पुराने पोर्टल-प्रतियाँ पुनर्वितरित न हों)।
5. संरचना, लाइसेंस और दायित्व का विवरण: मॉड्यूल रिपॉज़िटरी का README देखें।
