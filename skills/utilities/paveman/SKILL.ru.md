# Paveman — детерминированное сокращение файлов правил и памяти

> Тонкая, независимая от пользователя обёртка-навык вокруг отдельно поставляемого модуля `paveman`.
> Навык определяет, когда инструмент подходит, и описывает его безопасный порядок работы. Он не предполагает
> конкретной машины, фиксированного пути установки или персонального профиля.

## Когда срабатывает этот навык

Триггерами служат фразы пользователя, которые требуют сократить **существующий файл правил, соглашений или памяти**,
не меняя его смыслового содержания:

- «Сократи `<Datei>`» / «этот файл слишком длинный» / «обрезается при X символах или строках»
- «Сожми документацию, не трогая технику или код»
- «MEMORY.md или CLAUDE.md стал слишком большим»
- «Сделай этот файл правил короче, но оставь смысл без изменений»
- Любой вариант, который означает **сокращение существующего файла**, а не **новое написание** и не
  **перевод** (см. разграничение ниже)

**Это не** навык для:

- **`knappform`** — меняет то, как сама модель говорит в текущем диалоге (стиль общения LLM, на основе модели,
  без доступа к файлам). `paveman` вместо этого детерминированно меняет содержимое существующего файла
  без вызова модели. Оба могут сосуществовать; они технически и функционально разделены.
- **`bilingual-doc-sync`** — дополняет недостающие языковые версии. `paveman` сокращает одну версию
  и ничего не переводит.
- **`llm-text-hygiene`** — удаляет следы ИИ или остатки чата из текстов. Это иная цель, чем сокращение.
- Написание или выдумывание нового содержимого — `paveman` сокращает только то, что уже есть.

## Что умеет модуль

`paveman` — основанный на правилах, детерминированный сокращатель прозы для файлов Markdown и текста:
без вызова модели, без токенов и без отправки по сети. Способ поставки может отличаться в каждой системе;
определяющей является версия модуля или пакета, авторизованная именно там.

| Флаг | Действие |
|---|---|
| *(без флага)* | **Предварительный просмотр (по умолчанию).** Показывает diff и экономию символов, ничего не записывает. |
| `--apply` | Выполняет реальную запись; предварительно автоматически создаётся резервная копия. |
| `--rollback` | Восстанавливает последнюю резервную копию. |
| `--locker` | Сообщает об отклонениях путей или заголовков только как предупреждение, а не как ошибку. |
| `--kontext N` | Задаёт количество контекстных строк diff. |

**Валидатор защиты запускается при каждом вызове.** Блоки кода, пути и заголовки не должны изменяться.
В режиме по умолчанию отклонение препятствует записи, а не просто сообщается.

## Порядок работы — всегда в этой последовательности

1. **Сначала предварительный просмотр.** Запусти `paveman <Datei>` без `--apply`. Покажи пользователю
   экономию символов, diff и статус валидатора («OK» или конкретное сообщение об ошибке).
2. **Записывать только после явного подтверждения.** Лишь затем выполняй `paveman <Datei> --apply`;
   никогда не переходи из предварительного просмотра в режим записи автоматически.
3. **Упомяни `--rollback` до записи.** Пользователь должен заранее знать, как отменить нежелательный результат.
4. **Относись к ошибкам валидатора серьёзно.** Не используй `--locker` только для того, чтобы обойти ошибку.
   Сначала проверь, действительно ли отклонение безвредно; более мягкий режим требует осознанного решения пользователя.
5. **Уважай вручную отточенное содержимое.** Инструмент на основе правил не может надёжно определить, является ли
   формулировка намеренно подробной. При сомнениях внимательно проверь diff предварительного просмотра.

## Предварительное условие — проверка доступности модуля

1. С помощью `paveman --help` проверь, доступен ли CLI в текущем окружении.
2. Если команда отсутствует, определи авторизованный для этой системы путь к модулю или пакету. Не выдумывай
   локальную структуру путей, название пакета или репозиторий.
3. Если авторизованный источник не найден, сообщи о недостающем условии как о самостоятельном шаге настройки,
   вместо того чтобы слепо запускать навык или создавать параллельный модуль.
4. После установки сначала повторно выполни `paveman --help`, а затем безобидный предварительный просмотр;
   реальная проверка записи по-прежнему требует подтверждения.

## Примеры

```text
User: „Kürze meine CLAUDE.md, sie wird beim Sessionstart abgeschnitten.“

→ `paveman CLAUDE.md` (Trockenlauf)
→ Ergebnis: „12.400 → 9.800 Zeichen (-21 %), Validator: OK.“
→ Diff zeigen und auf `--rollback` hinweisen.
→ Nutzer bestätigt.
→ `paveman CLAUDE.md --apply`
```

```text
User: „MEMORY.md ist zu voll, kürze sie bitte.“

→ Trockenlauf: „893 → 893 Zeichen, keine Regel griff — der Text ist bereits knapp.“
→ Kein `--apply` empfehlen; den fehlenden Mehrwert ehrlich melden.
```
