# build-your-users-mind — публичный нейтральный указатель

Этот skill является лёгким указателем на публичный модуль
[`ellmos-ai/build-your-users-mind`](https://github.com/ellmos-ai/build-your-users-mind).
Полный метод, шаблоны, схемы, скрипты, тесты и документация исходных адаптеров
находятся в модуле. Этот каталог не дублирует его код.

## Возможности модуля

При явном разрешении оператора модуль помогает агенту:

1. извлекать настоящие сообщения пользователя из принадлежащих оператору
   журналов взаимодействия;
2. удалять чувствительные данные до постоянного хранения;
3. сокращать и классифицировать свидетельства о повторяющихся предпочтениях и
   решениях;
4. создавать локальную модель предпочтений с уровнями уверенности и
   происхождением;
5. подключать короткий указатель к выбранной среде агента;
6. калибровать прогнозы по последующей реальной обратной связи.

Публичный модуль предназначен для любого пользователя и поддерживаемой среды
агента. Он не содержит модель конкретного человека.

## Граница безопасности и конфиденциальности

- До чтения журналов взаимодействия требуется разрешение оператора.
- Личные профили, сырые журналы, корпуса свидетельств и локальные пути остаются
  приватными.
- Прогнозы являются неопределёнными гипотезами, а не чтением мыслей,
  диагностикой или заявлениями пользователя.
- Прогноз предпочтений никогда не расширяет полномочия агента.
- Внешние, необратимые, критичные для безопасности, юридические, медицинские,
  трудовые, финансовые и иные значимые действия требуют явного подтверждения.
- Созданные агентом прогнозы нельзя превращать в первичные свидетельства о
  пользователе.

## Установка

```bash
git clone https://github.com/ellmos-ai/build-your-users-mind.git <clone-path>
```

Следуйте актуальным `README.md`, `SKILL.md`, `SOURCE-ADAPTERS.md` и правилам
конфиденциальности модуля. Храните созданный профиль пользователя вне публичных
репозиториев. Репозиторий модуля является источником истины для реализации и
версий.

## Публичное ядро и приватные профили

`build-your-users-mind` — публичное нейтральное имя модуля.
`decision-avatar` — публичный протокол выполнения в этом каталоге. Аватар
конкретного человека, файлы свидетельств, локальные команды и индивидуальные
настройки являются приватными расширениями и не должны публиковаться под
персональным именем skill.
