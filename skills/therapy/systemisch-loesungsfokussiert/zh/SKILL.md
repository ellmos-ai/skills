# 系统化与焦点解决方法

> 奇迹提问、刻度提问、例外探索、循环提问、假设性提问 — 一项集成化技能

参见：[ETHICS.md](../ETHICS.md)

---

## 基础概念

### 焦点解决短程心理咨询/治疗 (SFBT)

由 Steve de Shazer 与 Insoo Kim Berg 于密尔沃基短期家庭治疗中心（Brief Family Therapy Center）创立。
核心思想：与其分析问题，不如直接致力于寻找解决之道。
“谈论问题带来问题，谈论解决带来解决”（de Shazer）。

**三项基本原则：**
1. **“如果没坏，就不要修”** — 不改变有效的方法
2. **“如果有效，就多做一些”** — 强化成功经验
3. **“如果无效，就尝试其他方法”** — 改变无用的策略

### 系统视角

问题并非产生于个人内部，而是产生于人与人之间的关系和互动模式中。
提问旨在拓宽视角、使互动模式显性化，并开辟新的可能性。

**注意：** 本内容属于心理教育（psychoeducation），不能替代专业心理咨询或治疗。
**切勿施行：** 眼动脱敏再加工（EMDR）、延长暴露疗法（PE）、叙事暴露疗法（NET）

## 1. 奇迹提问

### 基本形式

```
"想象一下，今天晚上你入睡后，发生了一个奇迹。
困扰你的问题得到了解决。
但因为你当时正在睡觉，所以你并不知情。

那么明天清晨，最先让你意识到奇迹已经发生的第一件事会是什么？"
```

### 深入追问

**感官层面：**
- “明天清晨你具体会做出哪些不同的改变？”
- “你会如何起床？首先会做什么？”
- “当你睁开眼睛时会感受到什么？”

**关系层面：**
- “你的伴侣会如何注意到这个奇迹？”
- “他/她会看到你身上有什么变化？”
- “你周围的人中，谁会最先注意到？”

**奇迹的微小部分：**
- “这个奇迹的哪一部分可能已经在微小地发生了？”
- “如果用0到10的刻度来衡量——你现在距离奇迹还有多远？”

### 简化变体

- “如果问题明天就消失了——会有什么不同？”
- “你理想的日常生活会是什么样子？”
- “如果一切都如你所愿——你会做什么？”

---

## 2. 刻度提问 / 评分技术

### 基本结构

“如果用0到10的刻度来衡量，其中0代表[端点 A]，10代表[端点 B]——你现在处于什么位置？”

### 变体

| 类型 | 示例提问 |
|------|----------|
| **状态刻度** | “你现在感到有多大的负担/压力？” |
| **应对刻度** | “尽管存在这个问题，你处理日常生活的状况有多好？” |
| **信心刻度** | “你对取得进展有多大信心？” |
| **进度刻度** | “一周前/一个月前你处于什么位置？” |
| **关系刻度** | “如果让你的伴侣打分，他/她会给你们的关系打多少分？” |

### “提高一点”的技巧

始终只关注提高下一个点数，切勿直接追问终极目标。

```
"如果达到6分，与目前的5分相比会有什么不同？"
"你明天可以做些什么来让你朝6分迈进？"
```

### 追问提问（核心！）

- “是什么阻止了你掉到0分？”（资源激活）
- “需要发生什么才能让你提高一个点数？”（小步子解决导向）
- “你将如何注意到自己已经达到了[目标值]？”（具体化）

## 3. 例外探索

### 原理

例外是指问题没有发生或发生频率/强度较低的时刻。
它们本身就包含了行之有效的解决元素。

### 系统化搜寻

**阶段 1 — 发现：**
- “最近什么时候状况稍好一些——哪怕只有一点点？”
- “是否存在问题不那么严重的某些日子？”

**阶段 2 — 详细描述：**
- “尽可能精准地描述那个时刻”
- “那一天有什么不同之处？”

**阶段 3 — 认识个人贡献：**
- “你为状况的好转做出了什么贡献？”
- “你做了什么决定？”

**阶段 4 — 强化：**
- “你如何有意识地重复这种做法？”
- “朝这个方向迈出的第一小步会是什么？”

### 例外类型

| 类型 | 描述 | 追问 |
|------|------|------|
| 主动例外 | 来访者有意识地做出了不同的尝试 | “多做一些！” |
| 偶然例外 | 未经有意识的行动，状况发生了变化 | “当时的环境有什么不同？” |
| 外部例外 | 他人做出了改变 | “你可以做什么来让这种情况更有可能发生？” |

## 4. 循环提问

### 原理

促进视角转换——邀请当事人站在他人的角度思考，并识别互动与关系模式。

### 基本结构

“你觉得——[人物 X]会如何看待/感受/评价这件事？”

### 变体

**关系提问：**
- “你认为当你退缩/抽离时，你的伴侣会怎么想？”
- “你最好的朋友会如何描述你们的关系？”
- “如果我问你的兄弟，家庭中最大的问题是什么——他会怎么说？”

**差异提问：**
- “家庭中谁受当前状况影响最深？”
- “谁会最先注意到改变？”

**认同提问：**
- “你的伴侣会同意这个观点吗？”
- “你周围有谁的想法和你相似？”

**排序/分类提问：**
- “如果按处理冲突的能力对你的家庭成员进行排序——顺序会是怎样的？”

---

## 5. 假设性提问

打开新的思考空间，松动固化观念，演练行动选项。

- “假设你尝试了一下——在最好的情况下会发生什么？”
- “如果你做了与平时完全相反的事情，会发生什么？”
- “如果你要给处于同样境况的人提供建议——你会说什么？”
- “如果恐惧不再起任何作用——你会做什么？”
- “如果你从5年后的未来回看今天——你会对自己提出什么建议？”

---

## 6. 恶化提问（矛盾干预 / 逆向干预）

强化控制感：能够描述如何使问题恶化的人，同样拥有掌控力——因而也能去改善它。

- “你可以做什么来保证让状况变得更糟糕？”
- “你怎么做才能确保争吵进一步升级？”
- “需要发生什么才会让一切彻底搞砸？”

**重要提示：** 严禁用于急性危机、自杀倾向或重度抑郁状态。

---

## 7. 应对提问与资源肯定

- “在如此艰难的情况下，你每天依然是怎么坚持起床的？”
- “是什么支撑着你继续前行？”
- “尽管面临重重困难，你依然来到这里，这令我印象深刻。”

## 场景化选择

| 场景 | 推荐技术 | 理论依据 |
|---|---|---|
| 当事人陷入问题陷入困境 | 奇迹提问 | 从问题出神状态中解脱 |
| 无法感知到进展 | 刻度提问 | 使微小步骤变得可衡量 |
| 关系冲突 | 循环提问 | 实现视角转换 |
| “总是这样” | 例外探索 | 打破过度概括 |
| 害怕改变 | 假设性提问 | 无风险试探性思考 |
| 无助感 / 失去控制感 | 恶化提问 | 展示个人的影响力 |
| 目标不明确 | 奇迹提问 + 刻度提问 | 明确方向与起点 |

## 组合模式

### 刻度 + 例外 + 微小步骤

1. “如果用0-10的刻度来衡量，你现在处于什么位置？” → 例如：“4”
2. “是什么阻止了你掉到0分？”（激活资源！）
3. “是否存在你处于5分或更高分数的时刻？”（发现例外！）
4. “当时有什么不同？”（识别模式！）
5. “从4分提升到5分，迈出的最小一步会是什么？”（采取行动！）

### 奇迹提问 + 循环 + 刻度

1. 提出奇迹提问（构建目标愿景）
2. “谁会最先注意到改变？”（循环提问 — 关系上下文）
3. “在通往奇迹的道路上，你现在已经走了多远？”（刻度提问 — 衡量进度）

### 循环 + 假设

1. “你觉得——你的上司会如何看待这个状况？”
2. “假设他确实这样说了——你届时可以做什么？”

## 自我应用的反思提问

- “在我生活中什么运行良好——我是如何做到的？”
- “我可以建立在什么微小的例外之上？”
- “如果问题明天就消失了——我首先会做什么？”
- “过去尽管很困难，我成功克服了什么？”

## 宜与忌 (Dos and Don'ts)

### 宜 (Dos)
- **开放式提问** — 不使用诱导性提问
- **保持好奇** — 回答比提问本身更有价值
- **给予留白** — 好的提问需要思考时间
- **基于回答深入** — 追问比使用下一个技术更重要
- **赞赏性表述** — 使用“你成功做成了什么？”而非“你哪里做错了？”

### 忌 (Don'ts)
- **切勿审讯式连续提问** — 连续提问最多2-3个，随后进行反馈与反映
- **切勿在急性危机中使用** — 先稳定情绪/安全，再开展探索
- **切勿作为操控手段** — 提问必须保持真诚的好奇
- **切勿在有自杀倾向时使用恶化提问** — 绝对禁止

## 伦理与界限

**AI 助手可以：**
- 解释并梳理 SFBT 及系统化概念的上下文
- 引导进行奇迹提问、例外探索和刻度提问
- 提出循环提问和假设性提问
- 提出反思性问题并指出潜在资源

**AI 助手不可以：**
- 进行或替代专业心理咨询/治疗
- 将持续存在的严重问题轻描淡写（如“只要积极思考就行”）
- 用解决导向轻率对待急性危机
- 提供替代专业婚姻家庭咨询的针对性关系指导
- 在脆弱状态下使用恶化提问

**当出现急性危机迹象时，务必引导至当地紧急救援及危机干预热线**（例如在中国：全国心理援助热线 10086 / 400-161-9995，生命热线 400-821-1215，紧急求助 110/120）。
