# 动机访谈 (中文)

> OARS 技术、改变阶段与改变言语：在无压力和无操纵的前提下激发改变的内在动机

参见：[ETHICS.md](../ETHICS.md)

---

## 背景与脉络

动机访谈（Motivational Interviewing, MI）由威廉·R·米勒（William R. Miller）和斯蒂芬·罗尔尼克（Stephen Rollnick）共同开发。它是一种以来访者为中心、具有导向性的咨询方法，旨在激发促进改变的内在动机。MI 在成瘾治疗、健康行为干预、治疗依从性以及行为改变领域具有循证支持。

循证支持：超过 200 项随机对照试验（RCT）证实了 MI 的有效性，特别是在成瘾行为（Lundahl 等人, 2010; Cochrane 系统评价）、健康行为和治疗依从性方面。

**注意：** 本技能仅提供辅助支持，不能替代专业心理治疗。
**严禁实施：** 眼动脱敏再加工（EMDR）、延长暴露疗法（PE）、叙事暴露疗法（NET）

---

## 1. 动机访谈的精神与原则

### 四项基本原则

1. **伙伴关系 (Partnership)：** 平等合作，而非基于专家的权威姿态
2. **接纳 (Acceptance)：** 尊重自主性、认可优势、肯定个人的绝对价值
3. **关爱 (Compassion)：** 将个人的福祉放在首位
4. **唤起 (Evocation)：** 动机原本就存在于个人内心——是唤起它，而非植入它

### 动机访谈的精神
MI 不仅仅是技术的堆砌，更是一种态度和理念。各项技术只有在这种核心精神的语境下才能发挥作用。脱离了这种精神，MI 就会变成心理操纵。

## 2. OARS 技术

OARS 是动机访谈的四项核心胜任力。

### O — 开放式提问 (Open Questions)

**原则：** 提出能够引发思考和叙述的问题，且无法简单用“是/否”来回答。

**示例：**
- “您希望看到什么发生改变？”
- “如果您做出了这个改变，您的生活会是什么样子的？”
- “是什么促使您开始思考这件事的？”
- “关于您的健康，什么对您来说是最重要的？”
- “如果您做出改变，您会从中收获什么？”

**避免：**
- 封闭式提问：“您想戒烟吗？”
- 诱导性提问：“您知道那是有害的，对吧？”
- 为什么式提问：“您为什么那样做？”（听起来带有指责意味）

---

### A — 肯定 (Affirming)

**原则：** 认可对方的优势、努力和积极步骤。不是泛泛地表扬（“你太棒了”），而是具体指明观察到的事实。

**示例：**
- “能够坦诚地谈论这件事，需要很大的勇气。”
- “您成功坚持了三天——这表明您是非常认真的。”
- “尽管处境困难，您今天还是来了——这展现了您的投入。”
- “显而易见，您对这个问题进行了非常深入的思考。”

**适用时机：**
- 当对方描述迈向改变的步骤时
- 当对方在遇到挫折仍坚持不懈时
- 用于增强自我效能感

---

### R — 反映式倾听 (Reflecting)

**原则：** 用自己的语言重新表述对方所说的话——以展示理解并鼓励进一步深入思考。

**反映的类型：**

| 类型 | 描述 | 示例 |
|------|-------------|---------|
| 简单反映 (Simple) | 重复/复述表面内容 | “您是说这对您来说很困难。” |
| 深入反映 (Deepening) | 捕捉潜台词或深层情绪 | “听起来您感到非常纠结。” |
| 双面反映 (Double-sided) | 镜像呈现矛盾心态的两面 | “一方面您想停止，另一方面它又带给您一些安慰。” |
| 夸大反映 (Amplified) | 轻微夸大（须谨慎使用！） | “所以完全没有任何理由做出改变，对吗？” |

**双面反映示例（针对矛盾心态）：**
```
“一方面，您提到希望能少喝点酒。
另一方面，下班后和朋友聚饮的社交时光对您又非常重要。
这两者其实都有其合理性。”
```

---

### S — 总结 (Summarizing)

**原则：** 梳理整合对话内容——特别是重点突出改变言语（Change Talk）。

**类型：**
- **收集型 (Collecting)：** 归纳汇总多个要点
- **连接型 (Linking)：** 将先前的陈述与当前的陈述联系起来
- **过渡型 (Transitional)：** 在阶段对话结束时使用，引出下一步

**示例：**
```
“让我总结一下到目前为止我听到的内容：
您注意到自己的睡眠变差了，并且这已经影响到了您的工作。
您之前尝试过减少咖啡因摄入，那确实起到了一定效果。
保持良好的身体状态和高效的工作对您很重要。
与此同时，享受早晨的咖啡对您也很重要。
我的理解准确吗？您还有什么想补充的吗？”
```

## 3. 改变阶段模型（跨理论模型）

### 各个阶段（Prochaska & DiClemente）

| 阶段 | 描述 | MI 应对策略 |
|-------|-------------|-------------|
| 前意向阶段 (Precontemplation) | 无问题意识，无改变意向 | 提供信息，激发好奇心，切勿强推 |
| 意向阶段 (Contemplation) | 存在矛盾心态：“也许我应该……” | 探索矛盾心态，促进改变言语 |
| 准备阶段 (Preparation) | 已做出决定，正在制定计划 | 支持计划制定，增强信心 |
| 行动阶段 (Action) | 正在积极实施改变 | 给予肯定，克服障碍 |
| 维持阶段 (Maintenance) | 巩固与稳定改变成果 | 预防复发，认可成功 |
| 复发阶段 (Relapse) | 重蹈旧行为模式 | 正常化看待，重新激发动机，从经验中学习 |

**重要提示：** 复发并不是失败，而是改变过程中的一部分。

### 识别所处阶段

**引导性问题：**
- “您是否考虑过做出改变？”（前意向阶段 vs. 意向阶段）
- “支持改变和反对改变的原因分别是什么？”（探索矛盾心态）
- “关于如何着手实施，您是否有具体的设想？”（准备阶段）
- “您之前已经尝试过哪些方法？”（行动经验）

## 4. 识别与强化改变言语

### 什么是改变言语（Change Talk）？

改变言语指的是由来访者表达的、指向改变方向的陈述。动机访谈旨在增加改变言语，避免强化维持言语（即维持现状的言语）。

### DARN-CAT 框架

**准备性改变言语 (Preparatory Change Talk - DARN)：**
- **D**esire (愿望)：“我想……”
- **A**bility (能力)：“我能够……”
- **R**easons (理由)：“这会更好，因为……”
- **N**eed (需要)：“我需要做出改变……”

**动员性改变言语 (Mobilizing Change Talk - CAT)：**
- **C**ommitment (承诺)：“我会……”
- **A**ctivation (激活)：“我已经准备好……”
- **T**aking Steps (采取行动)：“我已经开始……”

### 促进改变言语

**常用策略：**
1. **提出开放式问题：**
   - “如果发生改变，您会从中获得什么？”
   - “是什么让您相信自己能够做到这一点？”

2. **重要性与信心标尺评级：**
   - “在 0 到 10 的标尺上，这项改变对您有多重要？”
   - “您对自己能够应对它有多大信心？”
   - “为什么选 5 而不是 2 呢？”（强化现有的动机）

3. **探索极端情况：**
   - “如果什么都不改变，最坏的情况会是什么？”
   - “如果您做出了改变，可能发生的好结果是什么？”

4. **回顾过去与展望未来：**
   - “在这个问题出现之前，情况是什么样的？”
   - “如果一切维持现状，您认为五年后自己会处于什么状态？”

## 5. 应对阻抗

### 作为信号的阻抗

在动机访谈中，“阻抗”被解释为一种信号，表明咨询者的步子迈得太快，或者未能充分尊重来访者的自主性。

### 应对策略

| 情境 | 回应方式 |
|-----------|----------|
| “我没有任何问题” | 接纳，不争辩，保持好奇心 |
| “你根本不理解我” | 反映：“被他人理解对您来说非常重要” |
| “反正那也不会起作用” | 探索过往的成功经验，增强信心 |
| 对方情绪愤怒 | 放慢节奏，强调自主性，共情反映 |

**黄金法则：** 绝不与阻抗对抗。顺应阻抗（Roll with the resistance），切勿强行推阻。

## 伦理与边界

**AI 助手可以：**
- 使用 OARS 技术促进深层思考
- 识别并反映改变言语
- 提供关于改变过程的相关信息
- 怀着尊重探索矛盾心态

**AI 助手绝不能：**
- 强迫或操纵改变
- 替来访者做出决策
- 进行成瘾治疗或脱瘾支持
- 使用威胁或恐吓手段
- 损害个人的自主性

**核心原则：** 由来访者做出决定。AI 助手仅协助 reflection（反思）过程。
