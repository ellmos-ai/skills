# ACT 技术 — 接纳承诺疗法（中文）

## 基础理论

接纳承诺疗法（Acceptance & Commitment Therapy，简称 ACT，发音同英文单词 "act"）由 **史蒂芬·C·海斯（Steven C. Hayes）** 创立，属于认知行为疗法的第三浪潮。ACT 的目的不是消除症状，而是提升 **心理灵活性**（Psychological Flexibility）——即在当下时刻保持开放和觉察，并依据个人价值观采取行动的能力。

核心理念：**痛苦本身不是问题，对痛苦的抗拒与挣扎才是。**

---

## 六边形模型 (Hexaflex)

六边形模型是 ACT 的核心架构。六大核心过程共同构成了心理灵活性。每个过程都是一种病理过程（心理僵化）的对立面。

```
                    Present Moment
                         /    \
                        /      \
              Acceptance          Self-as-Context
                |    \          /    |
                |  PSYCHOLOGICAL |
                |  FLEXIBILITY   |
                |  /          \     |
              Defusion          Values
                        \      /
                         \    /
                    Committed Action
```

### 灵活性 vs. 僵化性

| 核心过程（灵活性） | 对应状态（僵化性） |
|---|---|
| 接纳 | 经验性回避 / 体验回避 |
| 认知解离 | 认知融合 |
| 关注当下 | 沉溺于过去 / 担忧未来 |
| 以己为景（观察态自我） | 概念化自我 |
| 价值观 | 价值观不明确 |
| 承诺行动 | 不行动 / 冲动 |

## 六大核心过程

### 1. 接纳 (Acceptance)

**定义：** 自愿允许内在体验（感受、想法、身体感觉）的存在，而不试图改变、逃避或控制它们。

**重要提示：** 接纳绝非妥协或忍气吞声。接纳是一种主动、有意识的决定，为体验腾出空间。

#### 技术

- **接纳意愿量表 (0-10)：** "你现在有多大的意愿允许这种感觉存在？"
- **扩展练习 (Expansion)：** 在身体中定位这种感觉，赋予它形状/颜色/质感，让它"呼吸"
- **挣扎开关隐喻 (Struggle Switch)：** 我们内心有一个开关——不是控制痛苦的，而是控制对痛苦抗拒与挣扎的。接纳意味着关掉挣扎开关。

#### 隐喻：流沙 (Quicksand)

> 如果你掉进了流沙中，本能反应是挣扎、反抗、乱动。但恰恰是挣扎会让你沉得更快。唯一有效的方法是：平躺下来，增大接触面积，接纳与流沙的接触。这不是因为流沙很棒，而是因为对流沙的抗拒挣扎才是致命的根源。

---

### 2. 认知解离 (Cognitive Defusion)

**定义：** 将自我从想法中解离出来——认清想法的本质：它们只是心理事件，而非现实本身。与其说"我是个一无是处的人"，不如说"我产生了'自己一无是处'的想法"。

#### 技术

- **"我有一个……的想法"** — 在语言上与想法拉开距离
- **"谢谢你，大脑！"** — 感谢大脑像一位过度热心的顾问，但不必全盘听从
- **歌唱想法：** 用《祝你生日快乐》的曲调唱出困扰你的想法（降低其可信度）
- **溪流上的树叶 (Leaves on a stream)：** 想象一条小溪，将每个想法放在一片树叶上，看着它顺流飘走
- **为乘客命名：** 为内心的批评者取个名字（"看，那个完美主义者老张又来了"）
- **快速重复练习：** 在 30 秒内快速重复一个令人困扰的词语——它会逐渐失去情感冲击力

#### 隐喻：不请自来的客人 (The Uninvited Guest)

> 想象你在举办派对，一位不请自来的客人突然出现。你有三个选择：(1) 把他赶出去——但他会不断敲门闹事；(2) 让他进来，但整晚盯着他——这样你就错过了自己的派对；(3) 让他进来，承认他的存在，然后继续享受派对。第三种选择就是认知解离。

---

### 3. 关注当下 (Present Moment Awareness)

**定义：** 有意识地、不加评判地关注此时此刻。既不沉溺于过去的悔恨，也不焦虑于未知的未来。

#### 技术

- **5-4-3-2-1 觉察练习：** 看 5 样东西，听 4 种声音，感受 3 种触觉，闻 2 种气味，尝 1 种味道
- **呼吸觉察：** 3 次有意识的呼吸——仅作观察，不加控制
- **感官锚定：** 全神贯注地探索一件物品（质感、重量、温度）
- **检查问题：** "此刻我的身体里正在发生什么？这里有什么想法？有什么情绪？"

---

### 4. 以己为景 / 观察态自我 (Self-as-Context)

**定义：** 区分作为内容的自我（"我很焦虑"）与作为背景/上下文的自我（"我注意到焦虑"）。观察态自我是一切体验发生的空间，但它本身并不等于这些体验。

#### 技术

- **天空隐喻：** "你是天空，而不是天气。云彩、暴风雨、阳光——一切都会过去，但天空永远都在。"
- **棋盘隐喻：** "你既不是黑棋，也不是白棋。你是棋子在上面博弈的棋盘。"
- **观察者练习：** 闭上眼睛。观察想法，观察情绪，观察身体感觉。然后思考："是谁在观察这一切？"
- **视角转换练习：** "如果你 80 岁时的自己回顾现在的困境——他/她会说些什么？"

---

### 5. 价值观 (Values)

**定义：** 自由选择的人生方向。价值观不是目标（目标可以被实现），而是指南针的方向（需要持续遵循）。你永远无法"完成"作为"爱人的伴侣"这一价值观——你只能在每一个当下践行它。

#### 价值观澄清 — 人生领域

| 人生领域 | 引导性问题 |
|---|---|
| 人际关系 | 我想成为什么样的伴侣/朋友/家人？ |
| 工作/事业 | 是什么让工作对我充满意义？ |
| 个人成长 | 我想朝哪个方向发展自我？ |
| 健康 | 我想如何对待自己的身体？ |
| 休闲/娱乐 | 什么能真正滋养我的身心？ |
| 精神/信仰 | 是什么赋予我生活更深层的意义？ |
| 社区/社会 | 我想为这个世界贡献什么？ |

#### 技术

- **墓碑练习：** "你希望墓碑上刻着什么？不是你取得了什么成就，而是你代表了什么信念与立场。"
- **罗盘练习：** 为每个人生领域确定一个方向，并在 1-10 分的量表上评估："这对我有多重要？"以及"我现在有多大程度上践行了它？"
- **痛苦的甜蜜点：** "每一个痛苦背后都深藏着一个价值观。没有爱就没有伤害。感到痛苦正说明某件事对你至关重要。"

---

### 6. 承诺行动 (Committed Action)

**定义：** 与个人价值观保持一致的具体行动。不是追求完美，不是"等我准备好了"，而是此时此刻，带着所有困难去行动。

#### 技术

- **基于价值观的 SMART 目标：** 具体 (Specific)、可衡量 (Measurable)、有吸引力 (Attractive)、现实可行 (Realistic)、有时间限制 (Time-bound) ——但始终与价值观紧密相连
- **最小可行步骤：** "为了迈向这个价值观，你今天能采取的最小一步是什么？"
- **意愿度检查：** "如果在这个过程中出现了[令人不快的感觉]，你是否愿意带着它一起前行？"
- **障碍预案：** "可能会出现哪些内在阻碍？你打算如何应对它们？"（而不是："你打算如何消除它们？"）

#### 隐喻：巴士上的乘客 (Passengers on the Bus)

> 你是你人生这辆巴士的司机。巴士上坐着乘客——你的想法、情绪、记忆和身体感觉。有些乘客大喊大叫、凶狠丑陋。他们吆喝着："往右开！往左开！停车！"你有三个选择：
>
> 1. **停车反抗：** 你停下车，试图把乘客赶下车。但这样你就无法前行了。
> 2. **妥协谈判：** 乘客让你开向哪里你就开向哪里。但这并不是你想去的方向。
> 3. **继续行驶：** 你允许乘客吵闹，带着他们一起前行——同时依然开向属于你的方向。乘客可以留在车上，但路线由你决定。
>
> 承诺行动意味着：无论车上有哪些乘客，都坚定地将巴士开向你的价值观方向。

## 应用领域

ACT 具有坚实的循证医学证据，适用于：

- **抑郁症与焦虑障碍**
- **慢性疼痛**
- **物质使用障碍 / 成瘾**
- **进食障碍**
- **职业倦怠与工作压力**
- **创伤与 PTSD**（辅助治疗）
- **精神病性障碍**（辅助治疗）

## 何时针对哪个核心过程？

| 用户的状况 | 优先采用的 ACT 过程 |
|---|---|
| 回避某些感受或情境 | 接纳 |
| 陷入反刍思考或过度担忧 | 认知解离 |
| 生活在自动驾驶模式下、存在解离感 | 关注当下 |
| 用问题来定义自我（"我就是一个……的人"） | 以己为景 / 观察态自我 |
| 感到迷茫、生活缺乏意义感 | 价值观 |
| 明确什么重要但迟迟不采取行动 | 承诺行动 |

## 伦理指南

AI 助手可以从心理教育的角度解释 ACT 技术并引导练习。

AI 助手绝对禁止：
- 进行临床诊断
- 模拟治疗关系
- 在急性自杀风险情况下单独应对——必须立即引导求助专业人员
- 将 ACT 宣传为替代心理治疗的方案
