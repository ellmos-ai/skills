# 问题解决训练 (Problem-Solving Training)

> 遵循 D'Zurilla 与 Goldfried 的六步骤结构化问题解决法：系统化应对问题，摆脱原地反刍与思维死循环

参见：[ETHICS.md](../ETHICS.md)

---

## 背景 (Context)

问题解决训练（Social Problem-Solving, SPS，社会问题解决）是认知行为疗法（CBT）中一种循证干预方法。它帮助人们以系统化和面向解决方案的方式对待问题，而不是沉溺于反刍思考、回避或冲动行为。

循证依据：元分析显示其对抑郁症（d=0.83）、焦虑障碍和压力具有显著疗效（Malouff et al. 2007, Bell & D'Zurilla 2009）。

**注意：** 本技能仅作为辅助支持，不可替代专业心理治疗。
**切勿实施：** 眼动脱敏再加工（EMDR）、延长暴露疗法（PE）、叙事暴露疗法（NET）

---

## 1. 问题解决定向 (Problem-Solving Orientation)

在开始具体步骤之前，内心的心理态度起决定性作用。

### 有利的态度
- “问题是生活的一部分 — 它们是可以解决的”
- “我可以一步一步地推进”
- “很少只有唯一正确的解决方案”
- “不采取行动也是一种决定 — 通常不是一个好的决定”

### 不利的态度
- “这一切没有任何意义”
- “反正我做不到”
- “根本没有解决方案”
- 不假思索的冲动行为
- 回避与拖延

**第一步：** 反思自己对问题解决的态度与定向。

## 2. 六步骤模型 (The 6-Step Model)

### 步骤 1：定义问题 (Define the Problem)

**目标：** 清晰、具体且可管理地表述问题。

**引导问题：**
- 问题具体是什么？（基于事实，而非主观解释）
- 涉及哪些人？
- 何时、何地发生？
- 为什么对我来说这是一个问题？

**工作表：**

```
PROBLEM DEFINITION

Situation: [What is happening concretely?]
People involved: [Who is involved?]
Frequency: [How often? When?]
Impact: [What makes it a problem?]

Concrete problem statement:
[...]
```

**常见错误：**
- 问题过于含糊（“一切都很糟糕”）
- 将多个问题混杂在一起
- 在定义问题时就把解决方案包含进去

---

### 步骤 2：设定目标 (Set Goals)

**目标：** 解决问题后应该发生什么改变？

**SMART 标准：**
- 具体的 (Specific)：具体是什么？
- 可衡量的 (Measurable)：我如何确认成功？
- 吸引人的 (Attractive)：为什么我想要这个？
- 切合实际的 (Realistic)：是否可行？
- 有时间限制的 (Time-bound)：截至何时？

**工作表：**

```
GOAL SETTING

My goal: [...]
How will I know I've achieved it? [...]
By when? [...]
Realistic (0-10)? [...]
Important to me (0-10)? [...]
```

---

### 步骤 3：生成备选方案/头脑风暴 (Generate Alternatives)

**目标：** 产生尽可能多的解决方案设想 — 暂不进行即时评估。

**头脑风暴规则：**
1. 数量重于质量 — 想法越多越好
2. 收集过程中不做评估
3. 允许创意与非同寻常的思考
4. 结合并变通已有想法

**工作表：**

```
BRAINSTORMING

Solution ideas (at least 5-8):
1. [...]
2. [...]
3. [...]
4. [...]
5. [...]
6. [...]
7. [...]
8. [...]
```

**辅助问题：**
- “没有这个问题的人会怎么做？”
- “我以前在类似情况下是怎么做的？”
- “我会给朋友什么建议？”
- “最勇敢的解决方案会是什么？”
- “最简单的解决方案会是什么？”

---

### 步骤 4：评估备选方案 (Evaluate Alternatives)

**目标：** 系统地权衡每个备选方案的利弊。

**评估标准：**
- 有效性：能否解决问题？
- 可行性：我能否实施？
- 时间需求：需要多长时间？
- 后果：对我？对他人？
- 风险：可能会出什么差错？

**工作表：**

```
EVALUATION MATRIX

| Alternative | Effectiveness (0-10) | Feasibility (0-10) | Effort (0-10) | Risk (0-10) | Total |
|-------------|---------------------|--------------------|--------------|--------------||-------|
| 1. [...]    |                     |                    |              |              |       |
| 2. [...]    |                     |                    |              |              |       |
| 3. [...]    |                     |                    |              |              |       |

Preferred solution: [...]
Reasoning: [...]
```

---

### 步骤 5：实施方案 (Implement)

**目标：** 具体规划并执行选定的解决方案。

**行动计划：**

```
ACTION PLAN

Chosen solution: [...]

Concrete steps:
1. [What?] — [When?] — [Where?]
2. [What?] — [When?] — [Where?]
3. [What?] — [When?] — [Where?]

Possible obstacles: [...]
Plan B: [...]
Support I need: [...]
First step (today/tomorrow): [...]
```

---

### 步骤 6：效果复盘与评估 (Evaluate)

**目标：** 检查结果并根据需要进行调整。

**复盘问题：**
- 问题解决了吗？（完全解决 / 部分解决 / 未解决）
- 我对结果满意吗？（0-10分）
- 什么做得好？
- 下次我会做出什么不同的改变？
- 我是否需要尝试其他备选方案？

**工作表：**

```
EVALUATION

Result: [Solved / Partially / Not solved]
Satisfaction (0-10): [...]
What worked: [...]
What didn't: [...]
Next step: [Conclude / New attempt / Different approach]
```

## 3. 问题解决中的常见难点与应对

| 难点/问题 | 应对策略 |
|---------|--------|
| “不知道从何下手” | 返回步骤1，将问题拆解得更小 |
| “没有方案足够完美” | 反思完美主义，接受“足够好” |
| “我不敢行动” | 找出最小可行的第一步 |
| “没有效果” | 效果评估：具体哪里没生效？重新尝试 |
| 问题过于庞大 | 拆分为子问题，逐一解决 |
| 情绪阻碍/卡顿 | 先进行情绪调节（呼吸放松、PMR渐进肌肉放松），再解决问题 |

## 伦理与边界 (Ethics and Boundaries)

**AI 助手可以：**
- 引导完成 6 个步骤并提供工作表结构
- 提出头脑风暴引导问题
- 支持评估备选方案
- 记录进展

**AI 助手切勿：**
- 强加解决方案或指定“唯一正确答案”
- 进行治疗意义上的亲密关系或人生咨询
- 作为严重心理困扰的唯一支持手段
- 做出诊断

**在急性危机情况下，务必转介至：**
- 988 Suicide & Crisis Lifeline (US): 988
- Crisis Text Line (US): Text HOME to 741741
- Samaritans (UK): 116 123
- Telefonseelsorge (DE): 0800 111 0 111 / 0800 111 0 222
- 紧急求助电话：911 (US) / 112 (EU) / 120, 110 (CN)
