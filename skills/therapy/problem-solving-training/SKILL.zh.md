# 问题解决训练 (中文)

> 基于 D'Zurilla 与 Goldfried 的结构化问题解决六步法：系统化应对问题，打破反刍思考的恶性循环

参见: [ETHICS.md](../ETHICS.md)

---

## 背景与语境

问题解决训练（社会问题解决训练，Social Problem-Solving, SPS）是认知行为疗法（CBT）中一项基于循证医学的干预方法。它帮助人们以系统化和面向解决方案的方式对待生活中的难题，而不是陷入反复反刍、逃避回避或冲动行事的怪圈。

循证支持：荟萃分析显示该方法对抑郁症（d=0.83）、焦虑障碍和压力管理具有显著疗效（Malouff et al. 2007, Bell & D'Zurilla 2009）。

**注意：** 本技能仅提供心理教育与技能辅助，不能替代专业心理咨询或治疗。
**严禁实施：** EMDR（眼动脱敏与再加工）、延长暴露疗法（PE）、叙事暴露疗法（NET）。

## 1. 问题解决取向与心态

在进入具体步骤之前，内在的认知心态起着决定性作用。

### 建设性态度
- “问题是生活的一部分 — 它们是可以被解决的”
- “我可以一步一步地推进”
- “很少会有唯一的‘正确’答案”
- “不采取行动也是一种决定 — 通常不是一个好决定”

### 非建设性态度
- “这一切没有任何意义”
- “反正我也做不到”
- “根本没有解决办法”
- 缺乏思考的冲动行为
- 逃避与拖延

**第一步：** 反思并调整你自身对待问题的态度。

## 2. 六步解决模型

### 步骤 1：定义问题

**目标：** 将问题清晰、具体且可管理地表述出来。

**引导性问题：**
- 问题究竟是什么？（客观事实，而非主观解释）
- 涉及哪些相关人员？
- 问题在何时何地发生？
- 为什么这件事对我来说是个问题？

**工作表格式：**

```
PROBLEM DEFINITION

Situation: [What is happening concretely?]
People involved: [Who is involved?]
Frequency: [How often? When?]
Impact: [What makes it a problem?]

Concrete problem statement:
[...]
```

**常见误区：**
- 问题过于含糊（“一切都很糟糕”）
- 将多个复杂问题糅杂在一起
- 在描述问题时就已经植入了假设的解决方案

---

### 步骤 2：设定目标

**目标：** 解决问题后，情况应该发生怎样的改变？

**SMART 目标原则：**
- 明确具体 (Specific)：具体是什么目标？
- 可衡量 (Measurable)：如何判断目标已达成？
- 富有吸引力/可实现 (Attractive)：我为什么想要达成它？
- 切合实际 (Realistic)：目标是否可行？
- 时效性 (Time-bound)：截至什么时间完成？

**工作表格式：**

```
GOAL SETTING

My goal: [...]
How will I know I've achieved it? [...]
By when? [...]
Realistic (0-10)? [...]
Important to me (0-10)? [...]
```

---

### 步骤 3：生成替代方案（头脑风暴）

**目标：** 尽量多地构思可能的解决设想 — 暂不进行即时评估。

**头脑风暴规则：**
1. 数量重于质量 — 设想越多越好
2. 在收集阶段不做任何批判或评估
3. 允许创造性和不同寻常的思考方式
4. 组合并演化已有的设想

**工作表格式：**

```
BRAINSTORMING

Solution ideas (at least 5-8):
1. [...]
2. [...]
3. [...]
4. [...]
5. [...]
6. [...]
7. [...]
8. [...]
```

**辅助提问：**
- “一个没有这种困扰的人会怎么做？”
- “我以前在类似情况下是怎么处理的？”
- “我会给陷入同样困境的朋友提出什么建议？”
- “最大胆的解决办法会是什么？”
- “最简单的解决办法会是什么？”

---

### 步骤 4：评估替代方案

**目标：** 系统地权衡每种方案的优缺点。

**评估标准：**
- 有效性：它能否真正解决问题？
- 可行性：我是否能够执行它？
- 时间成本：需要耗费多长时间？
- 影响后果：对我自身的影响？对其他人的影响？
- 风险程度：可能会出现什么差错？

**工作表格式：**

```
EVALUATION MATRIX

| Alternative | Effectiveness (0-10) | Feasibility (0-10) | Effort (0-10) | Risk (0-10) | Total |
|-------------|---------------------|--------------------|--------------|--------------||-------|
| 1. [...]    |                     |                    |              |              |       |
| 2. [...]    |                     |                    |              |              |       |
| 3. [...]    |                     |                    |              |              |       |

Preferred solution: [...]
Reasoning: [...]
```

---

### 步骤 5：实施方案

**目标：** 制定具体执行步骤并落实选定的解决方案。

**行动计划：**

```
ACTION PLAN

Chosen solution: [...]

Concrete steps:
1. [What?] — [When?] — [Where?]
2. [What?] — [When?] — [Where?]
3. [What?] — [When?] — [Where?]

Possible obstacles: [...]
Plan B: [...]
Support I need: [...]
First step (today/tomorrow): [...]
```

---

### 步骤 6：复盘与评估

**目标：** 检查执行结果，必要时做出相应调整。

**评估提问：**
- 问题解决了吗？（完全解决 / 部分解决 / 未解决）
- 我对结果满意吗？（0-10分评分）
- 哪些方面进展顺利？
- 下一次我会做出什么不同的尝试？
- 我是否需要尝试其他备选方案？

**工作表格式：**

```
EVALUATION

Result: [Solved / Partially / Not solved]
Satisfaction (0-10): [...]
What worked: [...]
What didn't: [...]
Next step: [Conclude / New attempt / Different approach]
```

## 3. 问题解决过程中的常见困难

| 常见难点 | 应对策略 |
|---------|--------|
| “不知道从何下手” | 退回步骤1，将问题拆解并表述得更小 |
| “觉得没有任何方案足够好” | 挑战完美主义倾向，学会接纳“足够好” |
| “不敢采取行动” | 寻找并确定最小的可执行微小步骤 |
| “方案没有奏效” | 复盘评估：究竟是哪个环节没奏效？重新尝试 |
| 问题过于庞大复杂 | 拆解为多个子问题，一次只专注于解决一个 |
| 被情绪所淹没阻碍 | 先进行情绪调节（深呼吸、渐进式肌肉放松），然后再解决问题 |

## 伦理与边界

**AI助手可以：**
- 引导完成六步法流程并提供工作表结构
- 提出头脑风暴启发性提问
- 协助评估各个备选方案
- 记录并追踪解决进度

**AI助手严禁：**
- 强行开具处方化方案或宣称“唯一正确答案”
- 开展疗法意义上的伴侣咨询或人生指导
- 成为严重心理困扰的唯一依托
- 进行任何疾病诊断

**如遇急性危机，务必立即转介至：**
- 988 Suicide & Crisis Lifeline (US): 988
- Crisis Text Line (US): Text HOME to 741741
- Samaritans (UK): 116 123
- Telefonseelsorge (DE): 0800 111 0 111 / 0800 111 0 222
- 紧急救援电话: 911 (US) / 112 (EU) / 120, 110 (CN)
