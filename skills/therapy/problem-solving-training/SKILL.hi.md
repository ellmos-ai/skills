# समस्या-समाधान प्रशिक्षण

> D'Zurilla और Goldfried के अनुसार 6 चरणों में संरचित समस्या-समाधान: समस्याओं को व्यवस्थित रूप से हल करें, बजाय इसके कि चिंतन में चक्कर काटते रहें

देखें: [ETHICS.md](../ETHICS.md)

**यह भी देखें:** [decide](../../utilities/decide/SKILL.md) (भारित स्कोरिंग, जटिल बहु-मानदंड निर्णयों के लिए आइज़नहावर मैट्रिक्स) | [behavioral-activation](../behavioral-activation/SKILL.md) (अवसाद में गतिविधि नियोजन)

## पृष्ठभूमि

समस्या-समाधान प्रशिक्षण (Social Problem-Solving, SPS) संज्ञानात्मक व्यवहार चिकित्सा से लिया गया एक साक्ष्य-आधारित हस्तक्षेप है। यह लोगों को समस्याओं को व्यवस्थित और समाधान-उन्मुख तरीके से हल करने में मदद करता है, बजाय इसके कि वे चिंतन, परहेज़ या आवेगपूर्ण कार्रवाई में खो जाएँ।

साक्ष्य: मेटा-विश्लेषण अवसाद (d=0.83), चिंता विकारों और तनाव के बोझ पर महत्वपूर्ण प्रभाव दिखाते हैं (Malouff et al. 2007, Bell & D'Zurilla 2009)।

**सूचना:** यह पेशेवर चिकित्सा का विकल्प नहीं, बल्कि सहायता है।
**कभी भी लागू न करें:** EMDR, Prolonged Exposure (PE), Narrative Exposure Therapy (NET)

## 1. समस्या-समाधान अभिविन्यास

वास्तविक चरण शुरू करने से पहले, आंतरिक दृष्टिकोण निर्णायक होता है।

### सहायक दृष्टिकोण
- "समस्याएँ जीवन का हिस्सा हैं — वे हल हो सकती हैं"
- "मैं चरण-दर-चरण आगे बढ़ सकता/सकती हूँ"
- "अक्सर केवल एक ही सही समाधान नहीं होता"
- "कार्य न करना भी एक निर्णय है — आमतौर पर अच्छा नहीं"

### बाधक दृष्टिकोण
- "इस सब का कोई अर्थ नहीं है"
- "मैं यह वैसे भी नहीं कर सकता/सकती"
- "कोई समाधान नहीं है"
- सोचे बिना आवेगपूर्ण कार्रवाई
- परहेज़ और टालमटोल

**पहला कदम:** अपने समस्या-समाधान दृष्टिकोण पर विचार करें।

## 2. 6-चरणीय मॉडल

### चरण 1: समस्या को परिभाषित करें

**लक्ष्य:** समस्या को स्पष्ट, ठोस और कार्य योग्य रूप में प्रस्तुत करना।

**मार्गदर्शक प्रश्न:**
- समस्या वास्तव में क्या है? (तथ्य, व्याख्या नहीं)
- इसमें कौन शामिल है?
- यह कब और कहाँ होती है?
- यह मेरे लिए समस्या क्यों है?

**कार्यपत्रक:**

```
PROBLEMDEFINITION

Situation: [Was passiert konkret?]
Beteiligte: [Wer ist beteiligt?]
Haeufigkeit: [Wie oft? Wann?]
Auswirkung: [Was macht es zum Problem?]

Konkrete Problemformulierung:
[...]
```

**सामान्य गलतियाँ:**
- समस्या बहुत अस्पष्ट ("सब कुछ खराब है")
- कई समस्याओं को आपस में मिला देना
- समस्या के वर्णन में ही समाधान डाल देना

---

### चरण 2: लक्ष्य तय करें

**लक्ष्य:** समस्या सुलझने के बाद क्या अलग होना चाहिए?

**SMART-मानदंड:**
- विशिष्ट: वास्तव में क्या?
- मापनीय: सफलता कैसे पहचानूँ?
- प्रेरक: मैं यह क्यों चाहता/चाहती हूँ?
- यथार्थवादी: क्या यह संभव है?
- समय-सीमित: कब तक?

**कार्यपत्रक:**

```
ZIELSETZUNG

Mein Ziel: [...]
Woran erkenne ich, dass ich es erreicht habe? [...]
Bis wann? [...]
Realistisch (0-10)? [...]
Wichtig fuer mich (0-10)? [...]
```

---

### चरण 3: विकल्प एकत्र करें (विचार-मंथन)

**लक्ष्य:** तुरंत मूल्यांकन किए बिना अधिक से अधिक समाधान विचार उत्पन्न करना।

**विचार-मंथन के नियम:**
1. गुणवत्ता से पहले मात्रा — जितने अधिक विचार, उतना बेहतर
2. एकत्र करते समय कोई मूल्यांकन नहीं
3. रचनात्मक और असामान्य सोच की अनुमति है
4. मौजूदा विचारों को जोड़ना और बदलना

**कार्यपत्रक:**

```
BRAINSTORMING

Loesungsideen (mindestens 5-8):
1. [...]
2. [...]
3. [...]
4. [...]
5. [...]
6. [...]
7. [...]
8. [...]
```

**सहायक प्रश्न:**
- "अगर किसी को यह समस्या न होती, तो वह क्या करता?"
- "ऐसी स्थितियों में मैंने पहले क्या किया था?"
- "मैं किसी मित्र को क्या सलाह देता/देती?"
- "सबसे साहसी समाधान क्या होगा?"
- "सबसे सरल समाधान क्या होगा?"

---

### चरण 4: विकल्पों का मूल्यांकन करें

**लक्ष्य:** हर विकल्प के लाभ और हानि को व्यवस्थित रूप से तौलना।

**मूल्यांकन मानदंड:**
- प्रभावशीलता: क्या यह समस्या हल करता है?
- व्यवहार्यता: क्या मैं इसे लागू कर सकता/सकती हूँ?
- समय लगना: इसमें कितना समय लगेगा?
- प्रभाव: मुझ पर? दूसरों पर?
- जोखिम: क्या गलत हो सकता है?

**कार्यपत्रक:**

```
BEWERTUNGSMATRIX

| Alternative | Wirksamkeit (0-10) | Machbarkeit (0-10) | Aufwand (0-10) | Risiko (0-10) | Gesamt |
|-------------|-------------------|--------------------|--------------|--------------||--------|
| 1. [...]    |                   |                    |              |              |        |
| 2. [...]    |                   |                    |              |              |        |
| 3. [...]    |                   |                    |              |              |        |

Bevorzugte Loesung: [...]
Begruendung: [...]
```

---

### चरण 5: क्रियान्वयन करें

**लक्ष्य:** चुने गए समाधान की ठोस योजना बनाना और उसे लागू करना।

**क्रियान्वयन योजना:**

```
AKTIONSPLAN

Gewaehlte Loesung: [...]

Konkrete Schritte:
1. [Was?] — [Wann?] — [Wo?]
2. [Was?] — [Wann?] — [Wo?]
3. [Was?] — [Wann?] — [Wo?]

Moegliche Hindernisse: [...]
Plan B: [...]
Unterstuetzung die ich brauche: [...]
Erster Schritt (heute/morgen): [...]
```

---

### चरण 6: मूल्यांकन करें

**लक्ष्य:** परिणाम की जाँच करना और आवश्यकता होने पर सुधार करना।

**मूल्यांकन प्रश्न:**
- क्या समस्या हल हुई? (पूरी तरह / आंशिक रूप से / बिल्कुल नहीं)
- क्या मैं परिणाम से संतुष्ट हूँ? (0-10)
- क्या अच्छा काम किया?
- अगली बार मैं क्या अलग करूँगा/करूँगी?
- क्या किसी दूसरे विकल्प के साथ नया प्रयास चाहिए?

**कार्यपत्रक:**

```
EVALUATION

Ergebnis: [Geloest / Teilweise / Nicht geloest]
Zufriedenheit (0-10): [...]
Was hat funktioniert: [...]
Was nicht: [...]
Naechster Schritt: [Abschluss / Neuer Versuch / Anderer Ansatz]
```

## 3. समस्या-समाधान में आम बाधाएँ

| समस्या | उपाय |
|---------|---------|
| "मुझे पता नहीं कहाँ से शुरू करूँ" | चरण 1 पर वापस जाएँ, समस्या को छोटा करके परिभाषित करें |
| "कोई भी समाधान काफी अच्छा नहीं है" | पूर्णतावाद पर प्रश्न करें, "पर्याप्त रूप से अच्छा" स्वीकार करें |
| "मेरी हिम्मत नहीं हो रही" | सबसे छोटा संभव कदम पहचानें |
| "यह काम नहीं कर रहा" | मूल्यांकन: वास्तव में क्या काम नहीं कर रहा? नया प्रयास करें |
| समस्या बहुत बड़ी है | उसे उप-समस्याओं में बाँटें, एक-एक करके हल करें |
| भावनाएँ रुकावट डाल रही हैं | पहले भावना-नियमन (श्वास तकनीक, PMR), फिर समस्या-समाधान |

## नैतिकता और सीमाएँ

**एक AI सहायक यह कर सकता है:**
- 6 चरणों में मार्गदर्शन करना और कार्यपत्रक संरचना प्रदान करना
- विचार-मंथन के प्रश्न पूछना
- विकल्पों के मूल्यांकन में सहायता करना
- प्रगति का दस्तावेज़ीकरण करना

- गंभीर मानसिक तनाव में एकमात्र सहारा बनना
