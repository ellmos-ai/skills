# Entrenamiento en Resolución de Problemas (Español)

> Resolución estructurada de problemas en 6 pasos según D'Zurilla y Goldfried: Abordar los problemas de forma sistemática en lugar de rumiar en círculos

Ver: [ETHICS.md](../ETHICS.md)

---

## Contexto

El Entrenamiento en Resolución de Problemas (Social Problem-Solving, SPS) es una intervención basada en la evidencia procedente de la terapia cognitivo-conductual. Ayuda a las personas a abordar los problemas de forma sistemática y orientada a la solución en lugar de perderse en la rumia, la evitación o la acción impulsiva.

Evidencia: Los metaanálisis muestran efectos significativos para la depresión (d=0,83), los trastornos de ansiedad y el estrés (Malouff et al. 2007, Bell & D'Zurilla 2009).

**Nota:** Esto es un apoyo, no un sustituto de la terapia profesional.
**Nunca implementar:** EMDR, Exposición Prolongada (PE), Terapia de Exposición Narrativa (NET)

---

## 1. Orientación hacia el problema

Antes de comenzar los pasos reales, la actitud interior es decisiva.

### Actitud útil
- "Los problemas son parte de la vida — tienen solución"
- "Puedo avanzar paso a paso"
- "Rara vez hay una sola solución correcta"
- "No actuar también es una decisión — por lo general no una buena"

### Actitud no útil
- "Nada de esto tiene sentido"
- "De todos modos no puedo hacerlo"
- "No hay solución"
- Acción impulsiva sin pensar
- Evitación y procrastinación

**Primer paso:** Reflexionar sobre la propia actitud hacia la resolución de problemas.

## 2. El modelo de los 6 pasos

### Paso 1: Definir el problema

**Objetivo:** Formular el problema de forma clara, concreta y manejable.

**Preguntas guía:**
- ¿Cuál es exactamente el problema? (Hechos, no interpretaciones)
- ¿Quién está involucrado?
- ¿Cuándo y dónde ocurre?
- ¿Por qué es un problema para mí?

**Hoja de trabajo:**

```
PROBLEM DEFINITION

Situation: [What is happening concretely?]
People involved: [Who is involved?]
Frequency: [How often? When?]
Impact: [What makes it a problem?]

Concrete problem statement:
[...]
```

**Errores comunes:**
- Problema demasiado vago ("Todo va mal")
- Mezclar múltiples problemas
- Incluir la solución en la formulación del problema

---

### Paso 2: Establecer objetivos

**Objetivo:** ¿Qué debería ser diferente después de resolver el problema?

**Criterios SMART:**
- Específico (Specific): ¿Qué exactamente?
- Medible (Measurable): ¿Cómo reconoceré el éxito?
- Atractivo (Attractive): ¿Por qué quiero esto?
- Realista (Realistic): ¿Es alcanzable?
- Limitado en el tiempo (Time-bound): ¿Para cuándo?

**Hoja de trabajo:**

```
GOAL SETTING

My goal: [...]
How will I know I've achieved it? [...]
By when? [...]
Realistic (0-10)? [...]
Important to me (0-10)? [...]
```

---

### Paso 3: Generar alternativas (Lluvia de ideas)

**Objetivo:** Generar tantas ideas de solución como sea posible — sin evaluación inmediata.

**Reglas de la lluvia de ideas:**
1. Cantidad sobre calidad — cuantas más ideas, mejor
2. Sin evaluación durante la recogida
3. Se permite el pensamiento creativo e inusual
4. Combinar y variar ideas existentes

**Hoja de trabajo:**

```
BRAINSTORMING

Solution ideas (at least 5-8):
1. [...]
2. [...]
3. [...]
4. [...]
5. [...]
6. [...]
7. [...]
8. [...]
```

**Preguntas de ayuda:**
- "¿Qué haría alguien que no tenga este problema?"
- "¿Qué he hecho antes en situaciones similares?"
- "¿Qué le aconsejaría a un amigo?"
- "¿Cuál sería la solución más audaz?"
- "¿Cuál sería la solución más sencilla?"

---

### Paso 4: Evaluar alternativas

**Objetivo:** Sopesar sistemáticamente los pros y los contras de cada alternativa.

**Criterios de evaluación:**
- Eficacia: ¿Resuelve el problema?
- Viabilidad: ¿Puedo implementarlo?
- Tiempo requerido: ¿Cuánto tiempo tomará?
- Consecuencias: ¿Para mí? ¿Para otros?
- Riesgos: ¿Qué podría salir mal?

**Hoja de trabajo:**

```
EVALUATION MATRIX

| Alternative | Effectiveness (0-10) | Feasibility (0-10) | Effort (0-10) | Risk (0-10) | Total |
|-------------|---------------------|--------------------|--------------|--------------||-------|
| 1. [...]    |                     |                    |              |              |       |
| 2. [...]    |                     |                    |              |              |       |
| 3. [...]    |                     |                    |              |              |       |

Preferred solution: [...]
Reasoning: [...]
```

---

### Paso 5: Implementar

**Objetivo:** Planificar concretamente y llevar a cabo la solución elegida.

**Plan de acción:**

```
ACTION PLAN

Chosen solution: [...]

Concrete steps:
1. [What?] — [When?] — [Where?]
2. [What?] — [When?] — [Where?]
3. [What?] — [When?] — [Where?]

Possible obstacles: [...]
Plan B: [...]
Support I need: [...]
First step (today/tomorrow): [...]
```

---

### Paso 6: Evaluar

**Objetivo:** Revisar el resultado y ajustar si es necesario.

**Preguntas de evaluación:**
- ¿Se resolvió el problema? (Totalmente / parcialmente / en absoluto)
- ¿Estoy satisfecho/a con el resultado? (0-10)
- ¿Qué funcionó bien?
- ¿Qué haría diferente la próxima vez?
- ¿Necesito un nuevo intento con una alternativa diferente?

**Hoja de trabajo:**

```
EVALUATION

Result: [Solved / Partially / Not solved]
Satisfaction (0-10): [...]
What worked: [...]
What didn't: [...]
Next step: [Conclude / New attempt / Different approach]
```

## 3. Problemas comunes en la resolución de problemas

| Problema | Solución / Remedio |
|---------|--------|
| "No sé por dónde empezar" | Volver al Paso 1, formular el problema a menor escala |
| "Ninguna solución es lo suficientemente buena" | Cuestionar el perfeccionismo, aceptar lo "suficientemente bueno" |
| "No me atrevo" | Identificar el paso más pequeño posible |
| "No funciona" | Evaluación: ¿Qué exactamente no funciona? Nuevo intento |
| El problema es demasiado grande | Dividir en subproblemas, uno a la vez |
| Las emociones bloquean | Primero regulación emocional (respiración, RMP), luego resolución de problemas |

## Ética y límites

**Un asistente de IA puede:**
- Guiar a través de los 6 pasos y proporcionar la estructura de la hoja de trabajo
- Hacer preguntas para la lluvia de ideas
- Apoyar la evaluación de alternativas
- Documentar el progreso

**Un asistente de IA NO debe:**
- Prescribir soluciones o sugerir "la respuesta correcta"
- Ofrecer asesoramiento de pareja o de vida en sentido terapéutico
- Ser el único apoyo para un malestar psicológico grave
- Realizar diagnósticos

**En caso de crisis aguda, derivar SIEMPRE a:**
- 988 Suicide & Crisis Lifeline (EE. UU.): 988
- Crisis Text Line (EE. UU.): Envía HOME al 741741
- Samaritans (Reino Unido): 116 123
- Telefonseelsorge (Alemania): 0800 111 0 111 / 0800 111 0 222
- Servicios de emergencia: 911 (EE. UU.) / 112 (UE)
