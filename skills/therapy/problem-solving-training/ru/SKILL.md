# Тренинг решения проблем (Русский)

> Структурированное решение проблем в 6 шагов по Д'Цурилла и Гольдфриду: Систематический подход к проблемам вместо навязчивого хождения по кругу

См.: [ETHICS.md](../ETHICS.md)

---

## Контекст (Context)

Тренинг решения проблем (Social Problem-Solving, SPS / Тренинг социальных навыков решения проблем) — это научно обоснованное вмешательство (интервенция) из когнитивно-поведенческой терапии. Он помогает людям подходить к проблемам систематически и ориентироваться на результат, а не погружаться в руминацию (мыслительную жвачку), избегание или импульсивные действия.

Доказательная база: Метаанализы показывают значимый эффект при депрессии (d=0,83), тревожных расстройствах и стрессе (Malouff et al. 2007, Bell & D'Zurilla 2009).

**Примечание:** Данный инструмент является поддержкой и не заменяет профессиональную психотерапию.
**Никогда не применять:** EMDR (ДПДГ), пролонгированную экспозицию (PE), нарративную экспозиционную терапию (NET)

## 1. Установка на решение проблем (Problem-Solving Orientation)

Прежде чем перейти к конкретным шагам, решающее значение имеет внутренняя установка.

### Конструктивная установка
- «Проблемы — это часть жизни, и они разрешимы»
- «Я могу двигаться шаг за шагом»
- «Редко существует только одно правильное решение»
- «Отсутствие действий — это тоже решение, и обычно не самое лучшее»

### Неконструктивная установка
- «В этом нет никакого смысла»
- «Я всё равно не справлюсь»
- «Решения не существует»
- Импульсивные действия без обдумывания
- Избегание и прокрастинация

**Первый шаг:** Проанализировать собственную установку на решение проблем.

---

## 2. Модель 6 шагов (The 6-Step Model)

### Шаг 1: Определение проблемы (Define the Problem)

**Цель:** Сформулировать проблему чётко, конкретно и доступно для решения.

**Наводящие вопросы:**
- В чём именно заключается проблема? (Факты, а не интерпретации)
- Кто в это вовлечён?
- Когда и где она возникает?
- Почему это является проблемой именно для меня?

**Рабочий лист:**

```
PROBLEM DEFINITION

Situation: [What is happening concretely?]
People involved: [Who is involved?]
Frequency: [How often? When?]
Impact: [What makes it a problem?]

Concrete problem statement:
[...]
```

**Типичные ошибки:**
- Проблема сформулирована слишком размыто («Всё плохо»)
- Смешивание нескольких проблем в одну
- Включение решения в саму формулировку проблемы

---

### Шаг 2: Постановка целей (Set Goals)

**Цель:** Что должно измениться после решения проблемы?

**Критерии SMART:**
- Specific (Конкретная): Что именно?
- Measurable (Измеримая): Как я пойму, что цель достигнута?
- Attractive (Привлекательная): Почему для меня это важно?
- Realistic (Реалистичная): Достижима ли она?
- Time-bound (Ограниченная по времени): К какому сроку?

**Рабочий лист:**

```
GOAL SETTING

My goal: [...]
How will I know I've achieved it? [...]
By when? [...]
Realistic (0-10)? [...]
Important to me (0-10)? [...]
```

---

### Шаг 3: Поиск альтернатив / Мозговой штурм (Generate Alternatives)

**Цель:** Сгенерировать как можно больше идей решений — без немедленной оценки.

**Правила мозгового штурма:**
1. Количество важнее качества — чем больше идей, тем лучше
2. Никакой оценки на этапе сбора
3. Приветствуется креативное и нестандартное мышление
4. Комбинируйте и модифицируйте уже имеющиеся идеи

**Рабочий лист:**

```
BRAINSTORMING

Solution ideas (at least 5-8):
1. [...]
2. [...]
3. [...]
4. [...]
5. [...]
6. [...]
7. [...]
8. [...]
```

**Вспомогательные вопросы:**
- «Что сделал бы человек, у которого нет этой проблемы?»
- «Что я делал(а) в похожих ситуациях раньше?»
- «Что бы я посоветовал(а) другу?»
- «Какое решение было бы самым смелым?»
- «Какое решение было бы самым простым?»

---

### Шаг 4: Оценка альтернатив (Evaluate Alternatives)

**Цель:** Систематически взвесить все «за» и «против» каждой альтернативы.

**Критерии оценки:**
- Эффективность: Решает ли это проблему?
- Выполнимость: Могу ли я это реализовать?
- Затраты времени: Сколько времени это займёт?
- Последствия: Для меня? Для окружающих?
- Риски: Что может пойти не так?

**Рабочий лист:**

```
EVALUATION MATRIX

| Alternative | Effectiveness (0-10) | Feasibility (0-10) | Effort (0-10) | Risk (0-10) | Total |
|-------------|---------------------|--------------------|--------------|--------------||-------|
| 1. [...]    |                     |                    |              |              |       |
| 2. [...]    |                     |                    |              |              |       |
| 3. [...]    |                     |                    |              |              |       |

Preferred solution: [...]
Reasoning: [...]
```

---

### Шаг 5: Реализация (Implement)

**Цель:** Конкретно спланировать и выполнить выбранное решение.

**План действий:**

```
ACTION PLAN

Chosen solution: [...]

Concrete steps:
1. [What?] — [When?] — [Where?]
2. [What?] — [When?] — [Where?]
3. [What?] — [When?] — [Where?]

Possible obstacles: [...]
Plan B: [...]
Support I need: [...]
First step (today/tomorrow): [...]
```

---

### Шаг 6: Проверка результатов и оценка (Evaluate)

**Цель:** Оценить результат и внести коррективы при необходимости.

**Вопросы для оценки:**
- Была ли проблема решена? (Полностью / частично / не решена)
- Удовлетворён(а) ли я результатом? (0-10)
- Что прошло успешно?
- Что бы я сделал(а) по-другому в следующий раз?
- Нужна ли новая попытка с другой альтернативой?

**Рабочий лист:**

```
EVALUATION

Result: [Solved / Partially / Not solved]
Satisfaction (0-10): [...]
What worked: [...]
What didn't: [...]
Next step: [Conclude / New attempt / Different approach]
```

## 3. Типичные трудности при решении проблем

| Проблема / Трудность | Решение |
|---------|--------|
| «Я не знаю, с чего начать» | Вернуться к Шагу 1, сформулировать проблему более локально/мелко |
| «Ни одно решение недостаточно хорошо» | Поставить под сомнение перфекционизм, принять принцип «достательно хорошо» |
| «Я не решаюсь» | Определить самый маленький из возможных шагов |
| «Это не работает» | Проверка: Что именно не сработало? Новая попытка |
| Проблема слишком велика | Разбить на подпроблемы, решать по одной за раз |
| Эмоциональный блок | Сначала регуляция эмоций (дыхание, ПМР — прогрессивная мышечная релаксация), затем решение проблемы |

## Этика и границы (Ethics and Boundaries)

**ИИ-ассистент может:**
- Сопровождать по 6 шагам и предоставлять структуру рабочих листов
- Задавать вопросы для мозгового штурма
- Помогать в оценке альтернатив
- Документировать прогресс

**ИИ-ассистент НЕ ДОЛЖЕН:**
- Предписывать решения или навязывать «единственно верный ответ»
- Проводить консультирование по вопросам отношений или жизненного выбора в терапевтическом смысле
- Быть единственной опорой при тяжёлом психологическом неблагополучии
- Ставить диагнозы

**В случае острого кризиса ВСЕГДА перенаправлять на:**
- 988 Suicide & Crisis Lifeline (США): 988
- Crisis Text Line (США): Отправьте HOME на 741741
- Samaritans (Великобритания): 116 123
- Telefonseelsorge (Германия): 0800 111 0 111 / 0800 111 0 222
- Единый телефон доверия (РФ): 8-800-2000-122 / 8-800-200-47-03
- Служба экстренных вызовов: 911 (США) / 112 (ЕС / РФ)
