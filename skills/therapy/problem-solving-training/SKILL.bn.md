# সমস্যা সমাধান প্রশিক্ষণ

> D'Zurilla ও Goldfried-এর পদ্ধতি অনুসারে ৬টি ধাপে কাঠামোবদ্ধ সমস্যা সমাধান: সমস্যাগুলোকে পদ্ধতিগতভাবে মোকাবেলা করুন, বৃত্তাকারে ঘুরপাক খেয়ে চিন্তা না করে

## পটভূমি

সমস্যা সমাধান প্রশিক্ষণ (Social Problem-Solving, SPS) হলো জ্ঞানমূলক আচরণ থেরাপি থেকে নেওয়া একটি প্রমাণভিত্তিক হস্তক্ষেপ। এটি মানুষকে গোছানো ও সমাধানমুখী উপায়ে সমস্যার মোকাবেলায় সাহায্য করে, যাতে তারা ক্রমাগত চিন্তায় ডুবে থাকা, এড়িয়ে যাওয়া বা আবেগতাড়িত আচরণে হারিয়ে না যায়।

প্রমাণ: মেটা-বিশ্লেষণে বিষণ্ণতা (d=0.83), উদ্বেগজনিত রোগ এবং মানসিক চাপে উল্লেখযোগ্য প্রভাব দেখা গেছে (Malouff et al. 2007, Bell & D'Zurilla 2009)।

**উল্লেখ্য:** এটি সহায়তা, পেশাদার থেরাপির বিকল্প নয়।
**কখনও বাস্তবায়ন করবেন না:** EMDR, Prolonged Exposure (PE), Narrative Exposure Therapy (NET)

## ১. সমস্যা সমাধানের দৃষ্টিভঙ্গি

প্রকৃত ধাপগুলো শুরু করার আগে অভ্যন্তরীণ মনোভাব নির্ণায়ক।

### সহায়ক মনোভাব
- "সমস্যা জীবনের অংশ — এগুলো সমাধানযোগ্য"
- "আমি ধাপে ধাপে এগোতে পারি"
- "সাধারণত একটিমাত্র সঠিক সমাধান থাকে না"
- "কিছু না করাও একটি সিদ্ধান্ত — তবে সাধারণত ভালো নয়"

### বাধাদায়ক মনোভাব
- "এসবের কোনো মানে নেই"
- "আমি এটা কোনোভাবেই পারব না"
- "কোনো সমাধান নেই"
- ভেবে না দেখে আবেগতাড়িত কাজ
- এড়িয়ে যাওয়া ও দীর্ঘসূত্রিতা

**প্রথম ধাপ:** নিজের সমস্যা সমাধানের মনোভাব প্রতিফলিত করুন।

## ২. ৬-ধাপের মডেল

### ধাপ ১: সমস্যার সংজ্ঞা

**লক্ষ্য:** সমস্যাটিকে স্পষ্ট, নির্দিষ্ট ও মোকাবেলাযোগ্যভাবে সংজ্ঞায়িত করা।

**পথনির্দেশক প্রশ্ন:**
- আসলে সমস্যাটি কী? (ব্যাখ্যা নয়, তথ্য)
- কারা জড়িত?
- কখন ও কোথায় এটি ঘটে?
- এটি আমার কাছে কেন সমস্যা?

**কর্মপত্র:**

```
PROBLEMDEFINITION

Situation: [Was passiert konkret?]
Beteiligte: [Wer ist beteiligt?]
Haeufigkeit: [Wie oft? Wann?]
Auswirkung: [Was macht es zum Problem?]

Konkrete Problemformulierung:
[...]
```

**সাধারণ ত্রুটি:**
- সমস্যা অস্পষ্ট ("সবকিছুই খারাপ")
- একাধিক সমস্যা মিশিয়ে ফেলা
- সংজ্ঞার ভেতরেই সমাধান ঢুকিয়ে দেওয়া

---

### ধাপ ২: লক্ষ্য নির্ধারণ

**লক্ষ্য:** সমস্যা সমাধানের পর কী ভিন্ন হওয়া উচিত?

**SMART-মানদণ্ড:**
- নির্দিষ্ট (Spezifisch): ঠিক কী?
- পরিমাপযোগ্য (Messbar): সফলতা কীভাবে বুঝব?
- আকর্ষণীয় (Attraktiv): আমি কেন এটা চাই?
- বাস্তবসম্মত (Realistisch): এটি কি সম্ভব?
- সময়সীমাবদ্ধ (Terminiert): কবে নাগাদ?

**কর্মপত্র:**

```
ZIELSETZUNG

Mein Ziel: [...]
Woran erkenne ich, dass ich es erreicht habe? [...]
Bis wann? [...]
Realistisch (0-10)? [...]
Wichtig fuer mich (0-10)? [...]
```

---

### ধাপ ৩: বিকল্প সংগ্রহ (ব্রেইনস্টর্মিং)

**লক্ষ্য:** তাৎক্ষণিক মূল্যায়ন ছাড়াই যতটা সম্ভব সমাধানের ধারণা তৈরি করা।

**ব্রেইনস্টর্মিংয়ের নিয়ম:**
1. গুণের আগে সংখ্যা — যত বেশি ধারণা, তত ভালো
2. সংগ্রহের সময় কোনো মূল্যায়ন নয়
3. সৃজনশীল ও অস্বাভাবিক চিন্তা অনুমোদিত
4. বিদ্যমান ধারণাগুলো একত্র করা ও পরিবর্তন করা

**কর্মপত্র:**

```
BRAINSTORMING

Loesungsideen (mindestens 5-8):
1. [...]
2. [...]
3. [...]
4. [...]
5. [...]
6. [...]
7. [...]
8. [...]
```

**সহায়ক প্রশ্ন:**
- "এই সমস্যা না থাকলে কেউ কী করত?"
- "আগে এমন পরিস্থিতিতে আমি কী করেছিলাম?"
- "একজন বন্ধুকে আমি কী পরামর্শ দিতাম?"
- "সবচেয়ে সাহসী সমাধান কোনটি হতো?"
- "সবচেয়ে সহজ সমাধান কোনটি হতো?"

---

### ধাপ ৪: বিকল্পগুলো মূল্যায়ন

**লক্ষ্য:** প্রতিটি বিকল্পের সুবিধা ও অসুবিধা পদ্ধতিগতভাবে বিবেচনা করা।

**মূল্যায়ন মানদণ্ড:**
- কার্যকারিতা: এটি কি সমস্যার সমাধান করে?
- বাস্তবায়নযোগ্যতা: আমি কি এটি করতে পারব?
- সময়ব্যয়: কতক্ষণ লাগবে?
- প্রভাব: আমার ওপর? অন্যদের ওপর?
- ঝুঁকি: কী ভুল হতে পারে?

**কর্মপত্র:**

```
BEWERTUNGSMATRIX

| Alternative | Wirksamkeit (0-10) | Machbarkeit (0-10) | Aufwand (0-10) | Risiko (0-10) | Gesamt |
|-------------|-------------------|--------------------|--------------|--------------||--------|
| 1. [...]    |                   |                    |              |              |        |
| 2. [...]    |                   |                    |              |              |        |
| 3. [...]    |                   |                    |              |              |        |

Bevorzugte Loesung: [...]
Begruendung: [...]
```

---

### ধাপ ৫: বাস্তবায়ন

**লক্ষ্য:** নির্বাচিত সমাধানটি সুনির্দিষ্টভাবে পরিকল্পনা ও সম্পাদন করা।

**বাস্তবায়ন পরিকল্পনা:**

```
AKTIONSPLAN

Gewaehlte Loesung: [...]

Konkrete Schritte:
1. [Was?] — [Wann?] — [Wo?]
2. [Was?] — [Wann?] — [Wo?]
3. [Was?] — [Wann?] — [Wo?]

Moegliche Hindernisse: [...]
Plan B: [...]
Unterstuetzung die ich brauche: [...]
Erster Schritt (heute/morgen): [...]
```

---

### ধাপ ৬: মূল্যায়ন

**লক্ষ্য:** ফলাফল যাচাই করা এবং প্রয়োজনে সমন্বয় করা।

**মূল্যায়ন প্রশ্ন:**
- সমস্যাটি কি সমাধান হয়েছে? (সম্পূর্ণ / আংশিক / একেবারেই না)
- আমি ফলাফলে সন্তুষ্ট কি? (০-১০)
- কোন বিষয়গুলো ভালো কাজ করেছে?
- পরের বার আমি কী ভিন্নভাবে করব?
- অন্য বিকল্প নিয়ে নতুন চেষ্টার প্রয়োজন আছে কি?

**কর্মপত্র:**

```
EVALUATION

Ergebnis: [Geloest / Teilweise / Nicht geloest]
Zufriedenheit (0-10): [...]
Was hat funktioniert: [...]
Was nicht: [...]
Naechster Schritt: [Abschluss / Neuer Versuch / Anderer Ansatz]
```

## ৩. সমস্যা সমাধানে সাধারণ বাধা

| সমস্যা | প্রতিকার |
|---------|---------|
| "কোথা থেকে শুরু করব জানি না" | ধাপ ১-এ ফিরে যান, সমস্যাটি আরও ছোট করে সংজ্ঞায়িত করুন |
| "কোনো সমাধানই যথেষ্ট ভালো নয়" | পরিপূর্ণতাবাদ যাচাই করুন, "যথেষ্ট ভালো" মেনে নিন |
| "সাহস পাচ্ছি না" | সবচেয়ে ছোট সম্ভাব্য পদক্ষেপ চিহ্নিত করুন |
| "কাজ হচ্ছে না" | মূল্যায়ন: ঠিক কী কাজ করছে না? নতুন চেষ্টা |
| সমস্যা অনেক বড় | উপ-সমস্যায় ভাগ করুন, একটি একটি করে |
| আবেগ বাধা দিচ্ছে | প্রথমে আবেগ নিয়ন্ত্রণ (শ্বাসপ্রশ্বাসের কৌশল, PMR), তারপর সমস্যা সমাধান |

## নৈতিকতা ও সীমারেখা

**একজন AI সহকারী যা করতে পারে:**
- ৬টি ধাপে পথ দেখানো এবং কর্মপত্রের কাঠামো সরবরাহ করা
- ব্রেইনস্টর্মিংয়ের প্রশ্ন করা
- বিকল্পগুলো মূল্যায়নে সহায়তা করা
- অগ্রগতি নথিবদ্ধ করা

**একজন AI সহকারী যা করতে পারবে না:**
- সমাধান চাপিয়ে দেওয়া বা "সঠিক উত্তর" ইঙ্গিত করা
- থেরাপিউটিক অর্থে সম্পর্ক বা জীবনের পরামর্শ দেওয়া
- গুরুতর মানসিক চাপের ক্ষেত্রে একমাত্র সহায়ক হওয়া
- রোগ নির্ণয় করা
