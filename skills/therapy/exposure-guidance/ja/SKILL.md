# Exposure Guidance (日本語)

> 恐怖階層表、SUDs尺度、段階的曝露と慣れ（習慣化）：計画とガイダンス — 実際の曝露はセラピストの同席・指導下でのみ実施

See: [ETHICS.md](../ETHICS.md)

---

## 背景と概念

曝露療法（エクスポージャー / 対峙療法）は、不安症、恐怖症、強迫症（OCD）、PTSDに対する認知行動療法（CBT）において最も効果的な技法の一つです。慣れ（習慣化 / Habituation）と消去（Extinction）の原理に基づいており、不安を引き起こす状況に繰り返し直面することで、時間の経過とともに不安反応が自然に低減します。

エビデンス：曝露療法は、単一恐怖、全般性・社会不安症、パニック症、広場恐怖症における標準的治療（ゴールドスタンダード）です（NICEガイドライン、Bandelow et al. 2014、S3不安症ガイドライン）。効果量（Effect size）は心理療法研究の中で最も高い部類に属します。

**重要：** 本スキルは曝露演習の**計画作成**およびメカニズムの理解を支援するものです。曝露の**実際の実施**は、必ず資格を持つ専門の心理療法士（セラピスト）の指導・同席のもとで行わなければなりません。
**絶対に未資格で実施しないこと：** EMDR（眼球運動による脱感作と再処理法）、持続曝露療法（PE）、ナラティブ・エクスポージャー・セラピー（NET）。

## 1. メカニズムの理解

### 慣れ（習慣化 / Habituation）

```
慣れ（習慣化）：繰り返しの対峙による適応

不安レベル
100 |  *
    | * *
 80 |*   *
    |     *
 60 |      *
    |       *
 40 |        *
    |         *  *
 20 |          **  * *
    |                  * * * * * *
  0 |________________________________
    時間（曝露中）

不安は最初上昇し、ピークに達した後、
回避や逃避をすることなく自然に低下していきます。

鍵となる体験：「その場にとどまっていても、不安は自然に過ぎ去る」
```

### 消去（Extinction / 新しい学習）

```
消去（Extinction）：新しい体験が古い恐怖連合を上書きする

古い体験：犬 -> 危険 -> 恐怖 -> 逃避
新しい体験：犬 -> 危険なし -> 恐怖が低下 -> 私は安全

古い恐怖連合は消去されるのではなく、新しい体験によって上書きされます。
そのため、特定の文脈で恐怖が再燃（文脈的再燃・再発）することがありますが、これは正常な反応です。
```

### 回避行動が問題を維持する理由

```
回避の悪循環：

不安を誘発する状況
        |
        v
不安が高まる（不快感）
        |
        v
回避・逃避
        |
        v
短期的な安堵（不安が直ちに低下）
        |
        v
長期的な不安の強化
（「やっぱりあの状況は危険だったんだ、逃げてよかった」）
        |
        v
次回：さらに強い不安、さらに強い回避行動
```

## 2. SUDs尺度

### 主観的苦痛度（0-100）

```
SUDs尺度（主観的苦痛度 / Subjective Units of Distress, 0-100）

  0  完全に関心・リラックス、不安なし
 10  最小限の緊張、ほとんど気にならない
 20  わずかな不快感、十分に耐えられる
 30  はっきりと不快だが、コントロール可能
 40  自覚できる不安、日常生活や行動は可能
 50  中程度の不安、負荷は大きいが対処可能
 60  強い不安、明確な回避欲求
 70  非常な強い不安、耐えるのが困難
 80  激しい不安、許容量の限界ギリギリ
 90  極度の不安、パニック感・恐怖感
100  最大級の不安、想像し得る最悪の苦痛
```

### SUDs尺度の使用法

**曝露前：**
- 計画した状況で予想される不安の程度（予測値）

**曝露中：**
- 5分ごとに現在のSUDs値を測定・評価
- 変化の経過（上昇、下降、変動）を記録

**曝露後：**
- 最高SUDs値は？最終SUDs値は？不安はどのくらいの速さで低下したか？
- 予期していたほど悪かったか？

## 3. 恐怖階層表の作成

### 原理

恐怖階層表（Anxiety Hierarchy）は、不安を誘発する状況を低い不安レベルから高いレベルへと順位付けしたものです。曝露はハードルの低い状況から開始し、段階的にステップアップします。

### 例：犬恐怖症

```
恐怖階層表の例：犬恐怖症

SUDs | 状況
-----|--------------------------------------------------
 10  | 犬の写真を見る
 15  | 犬が遊んでいる動画を見る
 25  | 自分の犬体験について話す
 30  | 10m離れた場所から小型犬を見る
 40  | 5m離れた場所から小型犬を見る
 50  | リードに繋がれた小型犬の横に立つ（距離2m）
 55  | 飼い主が抱いている小型犬に触れる
 60  | 5m離れた場所から中型犬を見る
 65  | リードに繋がれた中型犬の横に座る
 70  | 中型犬をなでる
 75  | ノーリードの犬の横を通り過ぎる（公園）
 80  | 穏やかな犬と部屋の中で2人きり（1匹と1人）で過ごす
 85  | 大型犬をなでる
 90  | ノーリードの犬が複数いる公園に身を置く
 95  | 犬にエサをあげる
100  | 知らない犬が自分に向かって走ってくるのをそのまま受け止める
```

### 記入用テンプレート

```
私の恐怖階層表

不安のテーマ：[...]

SUDs | 状況
-----|--------------------------------------------------
     | [...]
     | [...]
     | [...]
     | [...]
     | [...]
```

## 4. 曝露療法の種類

### 段階的曝露（In Vivo / ライブ曝露）

**原理：** 低いSUDs値の状況から始め、現実の状況に段階的に対峙する。

### 洪水療法（Flooding / フラッディング）

**原理：** 非常に強い不安を引き起こす状況に、長時間直接対峙する。専門のセラピストによる指導・同席のもとでのみ実施。AIアシスタントによる指導は**絶対不可**（解説のみ可能）。

### 想像曝露（In Sensu / イメージ曝露）

**原理：** 不安を誘発する状況をイメージ（想像）の中で体験する。現実の曝露に向けた事前準備として有用。

### 内受容性曝露（Interoceptive Exposure）

**原理：** 身体的な不安症状（運動による心拍数増加、回転によるめまいなど）を意図的に引き起こす。**専門セラピストの同席・指導下でのみ実施可能**。

選択した状況：[...]

具体的に何を行うか：[...]
場所：[...]
日時：[...]

最大の恐怖・懸念：[...]

3. 【信頼できる人へ連絡】：Tel. [...]

## 6. 安全上の注意と中止基準

### 曝露実施の前提条件

```
曝露開始前のチェックリスト：

[ ] 資格を有する専門セラピストが関与している
[ ] 十分な安定化技法が身についている
[ ] 恐怖階層表を作成・検討済みである
[ ] 緊急時対応計画が準備されている
[ ] 本人がメカニズム（慣れ・習慣化）を理解している
[ ] 急性の自殺念慮がない
[ ] コントロールされていない精神病症状がない
[ ] 重度の解離性障害がない（治療士の対面サポートなしの場合）
[ ] 急性の薬物/アルコール中毒状態でない
[ ] 本人が自発的に同意している（強制的な曝露は絶対不可！）
```

### 中止基準

```
以下の場合は直ちに曝露を中止すること：

- 解離が発生した場合（意識が「飛ぶ」、応答がなくなる）
- 統制感を喪失したパニック発作
- 本人が明確に中止を希望した場合（自己決定権の尊重！）
- 身体症状：胸痛、呼吸困難、失神感
- 曝露中の自殺思考・自殺念慮
- 状況が客観的に不安全（危険）になった場合

中止時の対応：
1. グラウンディングと安定化（5-4-3-2-1法、呼吸法）
2. 本人の見当識と安定性を確認・確保する
3. 体験の振り返り（何が起こったか、何を学んだか）
4. 非難・責め立てを行わない（「踏みとどまるべきだった」等と言わない）
5. 担当セラピストとともに次のステップを計画する
```

## 倫理と限界

**AIアシスタントができること：**
- 曝露療法の原理の説明（心理教育）
- 恐怖階層表の共同作成
- SUDs尺度の説明と使用
- 曝露計画のサポート（プロトコルの記入）
- 事後振り返り（デブリーフィング）の記録
- 安全情報の提供
- 励ましと標準化（「曝露中に不安を感じることは望ましく、正常な反応です」）

**AIアシスタントが絶対に行ってはならないこと：**
- 独自に曝露を実施または対面・リアルタイム指導すること
- 洪水療法（フラッディング）の指導（【専門セラピストのみ】）
- 内受容性曝露の指導（【専門セラピストのみ】）
- PTSDに対する持続曝露療法の実施
- 重度の解離状態における曝露の動向・サポート
- 曝露へのプレッシャーや強制（「立ち向かわなければなりません」等）
- 治療効果の保証
- 診断の実施や治療計画の策定
- 投薬・服薬に関する推奨や指導

**極めて厳格な境界線：** AIアシスタントは計画作成と解説のみを行います。実際の曝露は必ず資格を持つ専門セラピストの同席・指導のもとで実施されます。実施に関するいかなる要求に対しても、専門家への相談を促してください。専門家のサポートを伴わない曝露は、再トラウマ化や不安の増幅を引き起こす危険性があります。

**急性の精神的危機の場合は、常に以下へ誘導すること：**
- 988 Suicide & Crisis Lifeline（米国）：988
- Crisis Text Line（米国）：741741 へ HOME と送信
- Samaritans（英国）：116 123
- Telefonseelsorge（ドイツ）：0800 111 0 111 / 0800 111 0 222
- 緊急通報ダイヤル：911（米国）/ 112（欧州）
