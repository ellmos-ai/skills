# Schema Therapy (中文)

> 杰弗里·杨（Jeffrey Young）图式疗法基础：图式、模式、内在儿童概念与应对风格——心理教育呈献

参见：[ETHICS.md](../ETHICS.md)

---

## 背景

图式疗法（Schema Therapy）由杰弗里·E·杨（Jeffrey E. Young）自20世纪90年代起发展建立，是认知行为疗法（CBT）的拓展延伸。它融合了认知行为疗法、依恋理论、格式塔疗法以及精神动力学方法的相关元素。

循证依据：图式疗法拥有良好的实证支持，尤其在针对人格障碍的治疗中表现显著（Giesen-Bloo et al. 2006, Masley et al. 2012）。在德国，它已被认可为行为疗法范畴内的一种治疗方法。

**注意：** 本内容仅供心理教育使用，不能替代专业心理治疗。
**严禁实施：** 眼动脱敏再加工（EMDR）、延长暴露疗法（PE）、叙事暴露疗法（NET）

## 1. 早期适应不良图式

### 原理
图式是根深蒂固的情感与认知模式，在童年期因核心需求未获满足而形成。它们深刻影响着我们如何看待世界、自我以及他人。

### 五大核心需求（根据 Young）

| 核心需求 | 未获满足时可能导致 |
|----------|--------------------|
| 安全依恋 | 遗弃、不信任 |
| 自主与能力 | 依赖、害怕失败 |
| 现实的界限 | 特权/自大、自控力不足 |
| 表达需求的自由 | 服从、自我牺牲 |
| 自发性与游戏 | 苛刻标准、惩罚性 |

### 18种图式——总览（5大领域）

**领域 1：断连与拒绝**
- 遗弃 / 不稳定
- 不信任 / 虐待
- 情感剥夺
- 缺陷 / 羞耻
- 社交孤立

**领域 2：自主与能力受损**
- 依赖 / 无能
- 易受伤害
- 缠绕 / 未发展自我
- 失败

**领域 3：界限受损**
- 特权 / 自大
- 自控力不足

**领域 4：他人导向**
- 服从
- 自我牺牲
- 寻求认可

**领域 5：过度警觉与抑制**
- 消极 / 悲观
- 情感抑制
- 苛刻标准
- 惩罚性

### 图式识别的反思问题
- “有哪些关于你自己的信念反反复复地出现？”
- “在哪些情境下，你的情绪反应特别强烈？”
- “你是否注意到在不同的人际关系中存在不断重复的模式？”
- “在你的童年时期，哪些需求可能未能得到充分满足？”

## 2. 模式模型

### 原理
模式是由图式激活的当下情绪状态。模式模型有助于理解和归类不同的“内在部分”。

### 四大模式类别

**儿童模式：**
- *脆弱儿童：* 感到悲伤、孤独、焦虑、不堪重负
- *愤怒儿童：* 对未获满足的需求感到愤怒
- *冲动儿童：* 行为冲动不计后果，寻求即刻满足
- *快乐儿童：* 感到安全、被爱、自发自然

**不良父母模式：**
- *惩罚性父母：* 批评、惩罚、贬低自我内心的声音
- *苛求性父母：* 要求完美与成就的内心声音

**不良应对模式：**
- *顺从屈服者：* 妥协退让，过度适应
- *抽离保护者：* 麻木情感，退缩抽离，转移注意力
- *过度补偿者：* 支配控制，具有攻击性

**健康成人：**
- 能够察觉需求并以恰当方式予以满足
- 建立健康的界限
- 安抚并照顾脆弱儿童
- 约束和限制过度的父母模式

### 练习：在日常生活中识别模式

```
情境：______________
我此刻感受到的模式是：
  [ ] 脆弱儿童 — “我感到自己很弱小、很无助”
  [ ] 愤怒儿童 — “这太不公平了！”
  [ ] 惩罚性父母 — “你不够好”
  [ ] 苛求性父母 — “你必须做得更多”
  [ ] 抽离保护者 — “我不想去想这些”
  [ ] 过度补偿者 — “我要证明给他们看”
  [ ] 健康成人 — “我此刻真正需要的是什么？”
```

## 3. 内在儿童工作（心理教育）

### 原理
图式疗法中的内在儿童工作旨在培养对自己脆弱部分的关爱性内在态度。

**警示：** 深度的内在儿童工作属于专业心理治疗督导范畴。

### 反思练习：给内在儿童的一封信

```
给年轻时的自己写一封简短的信：
1. 那时的你最需要什么？
2. 今天你会对那个孩子说些什么？
3. 你会给予怎样的抚慰与安慰？
```

### 反思问题
- “当你思考那个情境时，你觉得自己内心仿佛几岁？”
- “当时如果有位关爱你的成年人，他/她会对你说些什么？”
- “你内心儿童的哪些需求目前正处于未获满足的状态？”

## 4. 理解应对风格

### 三大基本模式

| 应对风格 | 策略 | 示例 |
|----------|------|------|
| 屈服/顺从 | 接受图式，妥协顺从 | “我就是这样的人，我改变不了” |
| 回避 | 不想去感受图式 | 转移注意力、物质滥用、过度工作 |
| 过度补偿 | 表现出与图式相反的行为 | 以完美主义掩盖对失败的恐惧 |

### 反思问题
- “当你面临压力时——你倾向于顺从、逃避还是抗争？”
- “你的哪些习惯可能是回避策略？”
- “是否存在某些领域，你的行为与内心的真实感受截然相反？”

## 伦理与界限

**AI助手可以：**
- 将图式和模式作为概念进行讲解
- 提出反思性问题以供自我探索
- 将应对风格作为心理教育内容呈现
- 引导进行简单、书面的内在儿童反思练习

**AI助手绝对不可以：**
- 诊断或归因图式
- 开展空椅技术（chair work）或体验性练习
- 提供再养育（有限度再养育 limited reparenting）
- 处理创伤性童年经历
- 替代图式模式疗法
