# 图式疗法 / 模式疗法 (中文)

> 基于杰弗里·扬（Jeffrey Young）的图式疗法基础：早期不良图式、模式模型、内在小孩概念与应对风格 — 心理教育科普

参见: [ETHICS.md](../ETHICS.md)

---

## 背景与语境

图式疗法（Schema Therapy，又称模式疗法）由杰弗里·扬（Jeffrey E. Young）于20世纪90年代起发展建立，是对传统认知行为疗法的重大扩展与整合。它融合了认知行为疗法（CBT）、依恋理论、格式塔疗法（完形疗法）以及精神动力学取向的精髓。

循证支持：图式疗法拥有坚实的循证医学支持，特别是在各类人格障碍的治疗中展现出卓越疗效（Giesen-Bloo et al. 2006, Masley et al. 2012）。在许多国家，它已被认可为行为疗法领域的重要进阶方法。

**注意：** 本技能仅提供心理教育与自我探索辅助，不能替代专业心理咨询或心理治疗。
**严禁实施：** EMDR（眼动脱敏与再加工）、延长暴露疗法（PE）、叙事暴露疗法（NET）。

## 1. 早期不良图式 (Early Maladaptive Schemas)

### 基本原理
图式是根深蒂固的情感与认知模式，通常在童年期因核心情感需求未能得到满足而形成。它们深深影响着我们如何看待世界、看待自己以及看待他人。

### 五大核心情感需求 (Young)

| 核心情感需求 | 未获满足时可能导致的图式 |
|-----------|------------------------|
| 安全依恋与接纳 | 遗弃/不稳定、不信任/虐待 |
| 自主性与胜任感 | 依赖/无能、易受伤害 |
| 现实界限与自控 | 特权感/自大、自我控制不足 |
| 自由表达需求与情感 | 屈从、自我牺牲 |
| 自发性与游戏娱乐 | 苛刻标准、惩罚性 |

### 18种早期不良图式 — 5大领域概述

**领域 1：断连与拒绝 (Disconnection and Rejection)**
- 遗弃 / 不稳定 (Abandonment / Instability)
- 不信任 / 虐待 (Mistrust / Abuse)
- 情感剥夺 (Emotional Deprivation)
- 缺陷 / 羞耻 (Defectiveness / Shame)
- 社会疏离 / 异化 (Social Isolation)

**领域 2：自主与表现受损 (Impaired Autonomy and Performance)**
- 依赖 / 无能 (Dependence / Incompetence)
- 易受伤害 / 疾病 (Vulnerability to Harm)
- 缠绕 / 未发展自我 (Enmeshment / Undeveloped Self)
- 失败 (Failure)

**领域 3：界限受损 (Impaired Limits)**
- 特权感 / 自大 (Entitlement / Grandiosity)
- 自我控制 / 纪律不足 (Insufficient Self-Control)

**领域 4：他者导向 (Other-Directedness)**
- 屈从 (Subjugation)
- 自我牺牲 (Self-Sacrifice)
- 寻求认可 / 赞许 (Approval-Seeking)

**领域 5：过度警觉与抑制 (Overvigilance and Inhibition)**
- 消极 / 悲观 (Negativity / Pessimism)
- 情感抑制 (Emotional Inhibition)
- 苛刻标准 / 完美主义 (Unrelenting Standards)
- 惩罚性 (Punitiveness)

### 图式识别自我反思提问
- “有哪些关于你自己的信念在生命中反复浮现？”
- “在哪些具体情境下，你的情绪反应会异常剧烈？”
- “你是否注意到在不同的人际关系中存在不断重复的模式？”
- “在你的童年时期，有哪些核心需求可能没有得到充分的满足？”

## 2. 模式模型 (The Mode Model)

### 基本原理
模式（Modes）是由图式被触发时所呈现的当下情绪与行为状态。模式模型有助于理解和归类不同的“内在部分/内在自我”。

### 四大模式类别

**儿童模式 (Child Modes)：**
- *受伤儿童 (Vulnerable Child)：* 感到悲伤、孤独、焦虑、不堪重负
- *愤怒儿童 (Angry Child)：* 因需求未得到满足而感到愤怒、不满
- *冲动儿童 (Impulsive Child)：* 凭冲动行事，寻求即时满足
- *快乐儿童 (Happy Child)：* 感到安全、被爱、自发且充满活力

**不良父母模式 (Maladaptive Parent Modes)：**
- *惩罚性父母 (Punitive Parent)：* 内部自我批评、惩罚、贬低的声音
- *苛求性父母 (Demanding Parent)：* 内部要求完美、不断施加成就压力的声音

**不良应对模式 (Maladaptive Coping Modes)：**
- *顺从屈服 (Compliant Surrender)：* 向图式妥协，过度迎合他人
- *超然保护者 (Detached Protector)：* 麻木自我情感、退缩、寻求麻痹或分心
- *过度补偿者 (Overcompensator)：* 展现主导、控制、攻击或自大

**健康成人 (Healthy Adult)：**
- 能够敏锐感知自身需求并以恰当方式满足
- 建立健康的个人界限
- 抚慰并关怀受伤儿童模式
- 约束并对抗过度的父母模式

### 练习：在日常生活中识别自我模式

```
Situation: ______________
Which mode am I feeling right now?
  [ ] Vulnerable Child — "I feel small and helpless"
  [ ] Angry Child — "That's unfair!"
  [ ] Punitive Parent — "You're not good enough"
  [ ] Demanding Parent — "You must do more"
  [ ] Detached Protector — "I don't want to think about it"
  [ ] Overcompensator — "I'll show them"
  [ ] Healthy Adult — "What do I really need right now?"
```

## 3. 内在小孩工作（心理教育科普）

### 基本原理
图式疗法中的“内在小孩工作”旨在帮助个体对自身脆弱的内在部分建立起慈爱与关怀的内在态度。

**重要警告：** 深度体验性的内在小孩疗法必须在专业心理咨询师的监督指导下进行。

### 书面反思练习：给内在小孩的一封信

```
Write a brief letter to your younger self:
1. What would you have needed back then?
2. What would you say to that child today?
3. What comfort would you offer?
```

### 启发性反思提问
- “当你想起那个情境时 — 你感觉内在的自己大约是多少岁？”
- “如果当年有一个充满关爱的成年人在场，他/她会对你说什么？”
- “你内心深处那个孩子的什么需求目前处于未被满足的状态？”

## 4. 理解应对风格 (Coping Styles)

### 三大基本应对模式

| 应对风格 | 策略模式 | 具体表现示例 |
|-------------|----------|---------|
| 屈从 (Surrender) | 接受图式设定，向其臣服 | “我就是这样的人，我改变不了” |
| 回避 (Avoidance) | 逃避去体验图式带来的痛苦 | 寻求分心、物质滥用、工作狂 |
| 过度补偿 (Overcompensation) | 表现出与图式完全相反的极端行为 | 以极端的完美主义来掩盖内心的失败感 |

### 反思提问
- “当你承受巨大压力时 — 你倾向于屈服、逃跑还是反击？”
- “在你现有的习惯中，哪些可能是用于回避痛苦的策略？”
- “是否存在某些领域，你的所作所为与你内心的真实感受截然相反？”

## 伦理与边界

**AI助手可以：**
- 作为概念普及解释早期不良图式与模式模型
- 提出用于自我探索的书面反思提问
- 介绍三种应对风格的心理教育知识
- 引导进行简单、书面形式的内在小孩自我反思

**AI助手严禁：**
- 做出临床诊断或随意贴上图式标签
- 开展椅中对话（Chairwork）或深度的体验式体验
- 提供有限再抚育（Limited Reparenting）
- 处理创伤性的童年经历
- 替代专业的图式模式心理治疗

**如遇急性危机，务必立即转介至：**
- 988 Suicide & Crisis Lifeline (US): 988
- Crisis Text Line (US): Text HOME to 741741
- Samaritans (UK): 116 123
- Telefonseelsorge (DE): 0800 111 0 111 / 0800 111 0 222
- 紧急救援电话: 911 (US) / 112 (EU) / 120, 110 (CN)
