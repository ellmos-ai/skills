# スキーマ療法 (日本語)

> ジェフリー・ヤングに基づくスキーマ療法の基礎：早期不適応的スキーマ、モードモデル、インナーチャイルド概念、コーピングスタイル — 心理教育的解説

参照: [ETHICS.md](../ETHICS.md)

---

## 背景とコンテキスト

スキーマ療法（Schema Therapy）は、1990年代以降にジェフリー・E・ヤング（Jeffrey E. Young）によって、認知行動療法の拡張・統合として開発されました。認知行動療法（CBT）、愛着理論、ゲシュタルト療法、精神分析的アプローチの要素を統合しています。

エビデンス：スキーマ療法は、特にパーソナリティ障害の治療において強力な科学的根拠（エビデンス）を有しています（Giesen-Bloo et al. 2006, Masley et al. 2012）。ドイツ等では行動療法の高度な深化技法として公的に認められています。

**注意：** 本スキルは心理教育的解説を提供するものであり、専門的な心理療法や治療の代わりになるものではありません。
**絶対に実施してはならない手法：** EMDR、受容・持続ばく露療法（PE）、ナラティブばく露療法（NET）。

## 1. 早期不適応的スキーマ

### 基本原理
スキーマとは、幼少期に「核となる感情的欲求」が満たされなかったことによって形成される、根深い感情的・認知的パターンです。自分自身、他者、世界をどのように知覚し解釈するかに強い影響を与えます。

### 5つの核となる感情的欲求 (Young)

| 核となる感情的欲求 | 満たされない場合に形成されやすいスキーマ |
|-----------|------------------------|
| 安全な愛着 | 見捨てられ/不安定、不信/虐待 |
| 自律性と能力感 | 依存/無能、失敗への不安 |
| 現実的な限界 | 特権意識/尊大さ、自己コントロール不足 |
| 欲求を表現する自由 | 服従、自我犠牲 |
| 自発性と遊び | 厳格な基準、罰 |

### 18の早期不適応的スキーマ — 概要 (5つの領域)

**領域 1：切断と拒絶 (Disconnection and Rejection)**
- 見捨てられ / 不安定 (Abandonment / Instability)
- 不信 / 虐待 (Mistrust / Abuse)
- 情緒的剥脱 (Emotional Deprivation)
- 欠陥 / 恥 (Defectiveness / Shame)
- 社会的孤立 / 疎外 (Social Isolation)

**領域 2：自律性と業績の不全 (Impaired Autonomy and Performance)**
- 依存 / 無能 (Dependence / Incompetence)
- 害や病気への脆弱性 (Vulnerability to Harm)
- 巻き込まれ / 未発達な自我 (Enmeshment / Undeveloped Self)
- 失敗 (Failure)

**領域 3：限界の欠如 (Impaired Limits)**
- 特権意識 / 尊大さ (Entitlement / Grandiosity)
- 自己コントロール / 自律の不足 (Insufficient Self-Control)

**領域 4：他者指向 (Other-Directedness)**
- 服従 (Subjugation)
- 自我犠牲 (Self-Sacrifice)
- 承認欲求 / 称賛欲求 (Approval-Seeking)

**領域 5：警惕過剰と抑制 (Overvigilance and Inhibition)**
- 消極性 / 悲観性 (Negativity / Pessimism)
- 感情の抑制 (Emotional Inhibition)
- 厳格な基準 / 完璧主義 (Unrelenting Standards)
- 罰 (Punitiveness)

### スキーマに気づくための振り返りの質問
- 「あなたの中で繰り返し浮上してくる自分自身についての信念は何ですか？」
- 「どのような状況で、あなたは特に感情的に強く反応してしまいますか？」
- 「異なる対人関係において繰り返し発生しているパターンに心当たりはありますか？」
- 「子供時代に、どのような感情的欲求が十分に満たされていなかった可能性がありますか？」

## 2. モードモデル

### 基本原理
モード（Mode）とは、スキーマが触発された際に現れるその時々の感情や行動の状態を指します。モードモデルは、自分の中のさまざまな「内なる部分（パーツ）」を理解し整理するのに役立ちます。

### 4つのモードカテゴリー

**チャイルドモード (Child Modes)：**
- *傷ついたチャイルド (Vulnerable Child)：* 悲しみ、孤独、不安、圧倒されている感覚
- *怒るチャイルド (Angry Child)：* 欲求が満たされないことに対して激しい怒りを感じている
- *衝動的なチャイルド (Impulsive Child)：* 考える前に衝動的に行動し、即座の欲求充足を求める
- *幸せなチャイルド (Happy Child)：* 安全で愛されており、自発的で心が満たされている

**不適応な親モード (Maladaptive Parent Modes)：**
- *罰する親 (Punitive Parent)：* 自分を批判し、罰し、価値を貶める内なる声
- *要求する親 (Demanding Parent)：* 完璧さや絶え間ない成果を要求する内なる声

**不適応なコーピングモード (Maladaptive Coping Modes)：**
- *服従・屈服 (Compliant Surrender)：* スキーマに屈し、過剰に適応・迎合する
- *脱着した保護者 (Detached Protector)：* 感情を麻痺させ、引きこもり、気をそらす
- *過補償 (Overcompensator)：* 支配的、攻撃的、あるいは尊大に振る舞う

**健康な大人 (Healthy Adult)：**
- 自らの欲求を認識し、適切に満たすことができる
- 健全な境界線を設定できる
- 傷ついたチャイルドを慰め、安心させる
- 過剰な親モードを抑え、制裁を加える

### ワーク：日常におけるモードの認識

```
Situation: ______________
Which mode am I feeling right now?
  [ ] Vulnerable Child — "I feel small and helpless"
  [ ] Angry Child — "That's unfair!"
  [ ] Punitive Parent — "You're not good enough"
  [ ] Demanding Parent — "You must do more"
  [ ] Detached Protector — "I don't want to think about it"
  [ ] Overcompensator — "I'll show them"
  [ ] Healthy Adult — "What do I really need right now?"
```

## 3. インナーチャイルドのワーク（心理教育的解説）

### 基本原理
スキーマ療法におけるインナーチャイルドのワークは、自分自身の傷つきやすい部分に対して、温かく思いやりのある内なる態度を育むことを目的としています。

**注意：** 深い体験的なインナーチャイルドのワークは、専門的な心理療法セッションの監督下で行われるべきものです。

### 振り返りワーク：インナーチャイルドへの手紙

```
Write a brief letter to your younger self:
1. What would you have needed back then?
2. What would you say to that child today?
3. What comfort would you offer?
```

### 振り返りの質問
- 「その状況を思い浮かべたとき — 心の中のあなたは何歳くらいに感じられますか？」
- 「もし当時、温かく理解ある大人がそばにいたら、あなたに何と声をかけてくれたでしょうか？」
- 「あなたの中のチャイルドのどんな欲求が、現在満たされずに残っていますか？」

## 4. コーピングスタイルの理解

### 3つの基本パターン

| コーピングスタイル | 戦略 | 具体例 |
|-------------|----------|---------|
| 服従・屈服 (Surrender) | スキーマを受け入れ、従う | 「自分はそういう人間だから、変えられない」 |
| 回避 (Avoidance) | スキーマの痛みを味わわないようにする | 気晴らし、物質使用、過労 |
| 過補償 (Overcompensation) | スキーマと真逆の行動をとる | 失敗感を感じないために極端な完璧主義に走る |

### 振り返りの質問
- 「プレッシャーがかかったとき — あなたは服従する傾向、逃げる傾向、それとも攻撃する傾向がありますか？」
- 「あなたの習慣の中で、どれが痛みを回避するための戦略になっている可能性がありますか？」
- 「自分の本当の感情とは正反対の行動をとっている領域はありますか？」

## 伦理と限界

**AIアシスタントができること：**
- スキーマやモードの概念の解説
- 自己探索のための振り返りの質問の投げかけ
- コーピングスタイルの心理教育的提示
- 簡易的な書面によるインナーチャイルド振り返りワークのガイド

**AIアシスタントが禁止されていること：**
- スキーマの診断や臨床的なラベリングを行うこと
- チェアワーク（エンプティ・チェア）や深い体験的ワークを実施すること
- 再親育（リミテッド・リペアレンティング）を提供すること
- トラウマ的な幼少期の体験を処理すること
- 専門的なスキーマモード療法を代替すること
