# Schema Therapy (日本語)

> ジェフリー・ヤングによるスキーマ療法の基礎：スキーマ、モード、インナーチャイルド概念、コーピング・スタイル — 心理教育的アプローチ

参照：[ETHICS.md](../ETHICS.md)

---

## 背景

スキーマ療法（Schema Therapy）は、1990年代以降にジェフリー・E・ヤング（Jeffrey E. Young）によって認知行動療法の発展形として開発されました。認知行動療法（CBT）、愛着理論、ゲシュタルト療法、精神分析的アプローチの要素を統合しています。

エビデンス：スキーマ療法は、特にパーソナリティ障害の治療において高い科学的根拠（エビデンス）を有しています（Giesen-Bloo et al. 2006, Masley et al. 2012）。ドイツでは行動療法の枠組みにおける有効な手法として認められています。

**注意：** 本内容は心理教育（サイコエデュケーション）を目的としたものであり、専門的な心理療法の代わりとなるものではありません。
**絶対に実施してはならない技法：** EMDR、持続曝露療法（PE）、ナラティブ曝露療法（NET）

## 1. 早期不適応的スキーマ

### 原理
スキーマとは、幼少期に中核的感情欲求が満たされないことによって形成される、深く根づいた感情的・認知的なパターンです。私たちが世界、自分自身、そして他者をどのように知覚するかに影響を与えます。

### 5つの中核的感情欲求（ヤングによる）

| 中核的感情欲求 | 満たされない場合に生じうる結果 |
|----------------|--------------------------------|
| 安全な愛着 | 見捨てられ、不信 |
| 自律性と能力 | 依存、失敗への恐れ |
| 現実的な限界 | 尊大／特権意識、己律不足 |
| 欲求表現の自由 | 服従、自己犠牲 |
| 自発性と遊び | 厳格な基準、処罰 |

### 18のスキーマ — 概要（5つの領域）

**領域 1：切断と拒絶**
- 見捨てられ／不安定
- 不信／虐待
- 感情的剥奪
- 欠陥／恥
- 孤立／疎外

**領域 2：自律性と自立機能の損傷**
- 依存／無能
- 害や病気への脆弱性
- 巻き込まれ／未発達な自我
- 失敗

**領域 3：限界の損傷**
- 尊大／特権意識
- 己律不足／自制不足

**領域 4：他者指向性**
- 服従
- 自己犠牲
- 承認欲求

**領域 5：過剰警戒と抑制**
- 悲観／否定性
- 感情抑制
- 厳格な基準
- 処罰

### スキーマ認知のための自省の質問
- 「自分自身について、繰り返し浮かんてくる信念にはどのようなものがありますか？」
- 「どのような状況で、特に感情が強く揺さぶられますか？」
- 「人間関係の違いを超えて繰り返されるパターンに気づいていますか？」
- 「幼少期に十分満たされなかった可能性のある欲求は何ですか？」

## 2. モードモデル

### 原理
モードとは、スキーマによって活性化される一瞬一瞬の感情状態のことです。モードモデルは、さまざまな「内なる自分（部分）」を理解し整理するのに役立ちます。

### 4つのモードカテゴリ

**チャイルド・モード：**
- *傷ついたチャイルド：* 悲しみ、孤独、不安、圧倒される感覚を抱く
- *怒るチャイルド：* 満たされない欲求に対して怒りを感じる
- *衝動的なチャイルド：* 考えずに行動し、即座の欲求充足を求める
- *幸せなチャイルド：* 安心感、愛されている感覚、自発性を感じる

**不適応な親モード：**
- *罰を与える親：* 自分を批判・処罰・貶める内なる声
- *要求の厳しい親：* 完璧さや成果を要求する内なる声

**不適応なコーピング・モード：**
- *順応な服従者：* 屈服し、過剰に適応する
- *離脱したプロテクター：* 感情を麻痺させ、引きこもり、気をそらす
- *過剰補償者：* 支配し、コントロールし、攻撃する

**健康な大人：**
- 欲求を察知し、適切に満たすことができる
- 健康な境界線を設定する
- 傷ついたチャイルドを慰め、なだめる
- 過剰な親モードを制約・抑制する

### 演習：日常生活でモードに気づく

```
状況：______________
いま、どのモードを感じていますか？
  [ ] 傷ついたチャイルド — 「自分が小さく無力に思える」
  [ ] 怒るチャイルド — 「そんなの不公平だ！」
  [ ] 罰を与える親 — 「お前はダメな人間だ」
  [ ] 要求の厳しい親 — 「もっとやらなければならない」
  [ ] 離脱したプロテクター — 「考えたくない」
  [ ] 過剰補償者 — 「思い知らせてやる」
  [ ] 健康な大人 — 「いま、私は本当に何を必要としているだろうか？」
```

## 3. インナーチャイルド・ワーク（心理教育）

### 原理
スキーマ療法におけるインナーチャイルド・ワークは、自分自身の傷つきやすい部分に対して、思いやりのある内なる態度を育むことを目指します。

**注意：** 深いインナーチャイルド・ワークは、専門的な心理療法指導（スーパービジョン）のもとで行われるべきものです。

### 自省演習：インナーチャイルドへの手紙

```
幼い頃の自分へ短い手紙を書いてみましょう：
1. 当時、あなたは何を必要としていましたか？
2. 今のあなたなら、その子どもに何と言ってあげますか？
3. どのような慰めを差し伸べますか？
```

### 自省の質問
- 「その状況を思い浮かべるとき、内面では何歳くらいに感じられますか？」
- 「当時、思いやりのある大人がいたら、あなたに何と言ってくれたでしょうか？」
- 「あなたの中のチャイルドのどの欲求が、現在満たされないままになっていますか？」

## 4. コーピング・スタイルの理解

### 3つの基本パターン

| コーピング・スタイル | 戦略 | 例 |
|----------------------|------|----|
| 服従 | スキーマを受け入れ、屈服する | 「これが自分なんだから、変えられない」 |
| 回避 | スキーマを感じたくない | 紛らわし、物質使用、過重労働 |
| 過剰補償 | スキーマと真逆の振る舞いをする | 失敗だと感じないための完璧主義 |

### 自省の質問
- 「プレッシャーにさらされたとき — 服従、逃亡、闘争のどれに傾きやすいですか？」
- 「あなたの習慣のうち、どれが回避戦略である可能性がありますか？」
- 「実際に感じていることと真逆の行動をとってしまう領域はありますか？」

## 倫理と境界線

**AIアシスタントができること：**
- 概念としてのスキーマやモードを解説する
- 自己探求のための自省の質問を提示する
- 心理教育としてコーピング・スタイルを紹介する
- 簡単な書面によるインナーチャイルド自省演習をガイドする

**AIアシスタントがやってはならないこと：**
- スキーマの診断や特定の決めつけ
- チェアワーク（エンプティ・チェア）や体験的ワークの実施
- 再親育（リミテッド・リペアレンティング）の提供
- トラウマ的な幼少期体験の処理
- スキーマモード療法の代替となる対応

**急性の危機が発生した場合の緊急連絡先：**
- よりそいホットライン（日本）：0120-279-338
- 988 Suicide & Crisis Lifeline (US): 988
- Crisis Text Line (US): Text HOME to 741741
- Samaritans (UK): 116 123
- Telefonseelsorge (DE): 0800 111 0 111 / 0800 111 0 222
- 緊急通報：110/119 (JP) / 911 (US) / 112 (EU)
