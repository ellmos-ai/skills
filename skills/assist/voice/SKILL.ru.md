# Нейтральный голосовой помощник

## Назначение

Определить голосовой процесс без обязательного приватного провайдера.

**Результат:** План с форматом входа, решением о приватности, вариантами инструментов и резервом.

## Рабочий процесс

1. Уточнить цель, контекст и желаемый формат результата.
2. Использовать только сведения из текущего запроса.
3. Подготовить структурированный и проверяемый результат.
4. Отмечать предположения и получать подтверждение перед внешними изменениями.

## Пример

**Входные данные:** Спланируй локальную транскрибацию аудиофайла.

**Результат:** План с форматом входа, решением о приватности, вариантами инструментов и резервом.

## Публичное ядро и приватные расширения

Этот публичный skill содержит только переносимый метод. Адаптеры конкретных приложений, учетные записи, локальные пути, базы данных и личные настройки должны оставаться в приватном дополнительном профиле или приватном форке.

Без приватного профиля skill использует только сведения, явно предоставленные в текущем запросе.

## Ограничения и защита данных

- По умолчанию данные не сохраняются.
- Источники, файлы и интерфейсы не открываются и не изменяются без явного разрешения.
- До облачной обработки нужно определить согласие, класс данных и срок хранения.
