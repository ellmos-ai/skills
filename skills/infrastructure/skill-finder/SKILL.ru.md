# Поисковик навыков (Skill-Finder)

## Правило

Перед началом любой нетривиальной задачи сначала проверьте, справится ли с ней лучше локальный навык. Даже при малейшем подозрении загрузите соответствующий навык и **следуйте его живым инструкциям** (читайте файл, не работайте по памяти). Если ни один навык не подходит, продолжайте в обычном режиме.

## Тревожные флаги (Рационализации, означающие СТОП)

| Мысль | Реальность |
|---------|----------|
| "Это просто быстрый вопрос." | Вопросы — это задачи; сначала проверьте навыки. |
| "Я знаю эту концепцию." | Знать концепцию ≠ использовать навык. Читайте живой файл. |
| "Навык — это избыточно." | Простое становится сложным — используйте навык. |
| "Я сначала сам изучу." | Навыки говорят, КАК изучать. Сначала проверьте. |
