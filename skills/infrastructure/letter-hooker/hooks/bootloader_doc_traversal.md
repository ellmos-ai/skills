# Bootloader: Document Traversal

Use this procedure before making project changes.

1. Start at the active working directory and identify the repository root. Do not assume that the current directory is the user's home or the only project root.
2. Read the task instructions first, then applicable repository instructions such as AGENTS.md or CLAUDE.md. Read the root README and task-relevant START, RULES, TASK, TODO, and architecture documents before editing.
3. If the current project directory has no governing instructions, move up one directory at a time and check each parent. Stop at the repository root or the authorized workspace boundary.
4. Resolve a relative path from the document that contains it. Verify that the target exists and belongs to the current repository or another explicitly authorized location.
5. Follow the order and scope stated by the current task. Keep project-specific instructions and global rules visible while working.
6. When two sources disagree, prefer the current user instruction for the task, then applicable repository rules and current source files. Treat remembered notes as historical context and verify facts that can drift.
7. If the authoritative source or target remains unclear, stop before writing and report the concrete ambiguity.
