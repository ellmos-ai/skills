# Decision Avatar

## 目的

この Skill は個人を複製するものではありません。繰り返し発生する意思決定タイプにおいて、正当で承認された証拠から可能性の高い選好を導き出すための検証可能な手順を提供します。

ローカルの意思決定プロファイルが存在し、その使用が現在のタスクに対して許可されている場合にのみ使用してください。プロファイルがない場合、Skill は代替の決定を提供しません。

タスク、適用されるエージェントルール、またはプロファイルメタデータが現在の目的を明示的に許可している場合にのみ、使用が承認されたとみなされます。単にプロファイルファイルにアクセスできるだけでは同意とはみなされません。

## 基本原則

1. **推測より証拠。** 直接的な発言や確認された決定は、導き出されたパターンよりも重みがあります。
2. **予測は個人の発言ではない。** エージェントの出力が新しい一次証拠としてプロファイルにフィードバックされてはなりません。
3. **決定と実行は異なる。** 実施に追加の権限が必要である場合でも、推奨事項自体は明確であり得ます。
4. **沈黙の同意はフィードバックではない。** 異議がないからといって予測が確認されたことにはなりません。
5. **プロファイルはローカルかつプライベートに保つ。** 個人データ、シークレット、または機密コンテンツを共有スキルファイルに取り込まないでください。

## ポータブルプロファイルモデル

ファイル名は自由に設定可能です。必要なのは以下の役割のみです：

| 役割 | 内容 |
|---|---|
| メソドロジー | エビデンスレベル、データ保護、およびキャリブレーションルール |
| 実証済み選好 | 直接的な発言および確認された決定 |
| 仮説 | 確信度と情報源を伴う導出ルール |
| アクション | 予測に基づいて実行された行動 |
| フィードバック | 個人による確認、修正、または拒絶 |

プロジェクト関連の最新の決定は、一般的な選好よりも優先されます。

処理されるすべての証拠には、少なくとも以下が含まれている必要があります：

```text
Quellen-ID:
Datum:
Entscheidungstyp und Gültigkeitsbereich:
Status: bestätigt/korrigiert/widerrufen
Gültig bis: <optional>
```

撤回された、期限切れの、または適用範囲外の証拠は使用しないでください。矛盾する確認済み証拠がある場合は、まずより具体的なものが優先され、次に最新のものが優先されます。競合が解決しない場合は、確信度を「低」に設定してエスカレーションしてください。

## 意思決定ループ

### 0. ローカル優先ルールの確認

現在のプロジェクトまたは具体的な意思決定タイプに対して確認済みのルールが存在する場合は、それを使用し、その情報源をドキュメント化します。

### 1. 実際の証拠の検索

ローカルのメソドロジーに従って許容される証拠のみを使用してください。タスクリスト、エージェントログ、以前のアバターの応答、および現在のセッションの議論は、個人の発言ではありません。

### 2. 予測の形成

結果は常に理由と3つのレベルのいずれかを添えて出力します：

- **高 (high):** 複数の直接的で一貫性があり、関連性の高い証拠、
- **中 (medium):** 限られたまたは間接的な証拠を伴うもっともらしいパターン、
- **低 (low):** 初めての状況、矛盾する証拠、または信頼できるパターンの不在。

重大な決定が自動的に「低」になるわけではありません。確信度は選好に対する証拠を測定するものであり、その後の実行の範囲を測定するものではありません。

### 3. モードの分離

| モード | 結果 | 副作用 |
|---|---|---|
| 予測 | 可能性の高い立場 + 証拠 + 確信度 | なし |
| 決定 | 具体的な選択 + 理由 + 確信度 | なし |
| 実行 | 承認された安全な実施 + アクションログ | あり得る |

実行モードでは、ランタイムの権限と安全ルールがさらに適用されます。確信度が低い場合や実行権限がない場合は、黙って実行するのではなくエスカレーションにつながります。

### 4. フィードバックのキャリブレーション

実際のフィードバックの後：

1. 予測を確認済み、修正済み、または拒絶としてマークします。
2. オプションで評価スケールを記録します。
3. 方向性のエラーと適合/トリミングのエラーの違いを記録します。
4. 仮説と確信度を調整します。
5. 真正なフィードバックのみを実証済み選好に取り込みます。

## 出力フォーマット

```text
Entscheidungstyp:
Modus:
Wahrscheinliche Präferenz:
Konfidenz:
Zulässige Belege:
Gegenbelege oder Unsicherheit:
Ausführung autorisiert: ja/nein
Nächster Schritt:
```

出力には、編集済みのソースIDと決定に必要な証拠の要約のみを記載してください。プライベートな発言、絶対プロファイルパス、または機密性の高い生データを再現しないでください。

## 制限事項

- 個人の内部状態に関する診断や断言を行わない。
- 許可された目的以外でプロファイルを使用しない。
- エージェントの推測を個人の知識として自動的に採用しない。
- 新しい権限が必要な場合、予測のみに基づいて実行しない。
