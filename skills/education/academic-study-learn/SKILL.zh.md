# 主动学习与知识结构化指南 (中文版)

本技能提供主动回忆、费曼技巧及结构化笔记方法，以促进深度理解与长期记忆。

## 1. 概述与目标

- **主动回忆与间隔重复：** 巩固长期记忆的高效复习策略。
- **费曼技巧：** 用通俗语言解释复杂概念，精准发现知识盲区。
- **结构化笔记：** 运用康奈尔笔记法与概念图谱整理知识体系。

## 2. 工作流程与执行步骤

1. **分析性阅读：** 提炼核心观点与关键概念。
2. **自我阐述：** 脱离资料，用自己的语言重述知识点。
3. **查漏补缺：** 针对复述不清的环节重新研读教材。
4. **归纳总结：** 制作精炼的复习提纲与卡片。

## 3. 不可逾越的边界与规则

- **注重理解：** 坚持逻辑理解高于机械背诵。
- **严谨出处：** 确保知识点来源于权威学术文献。
