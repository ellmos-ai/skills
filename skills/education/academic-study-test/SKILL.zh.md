# 考试备考与模拟测试指南 (中文版)

本技能支持设计模拟试题、限时自我测试及错题深度诊断分析。

## 1. 概述与目标

- **模拟试题设计：** 涵盖主观题与客观题的全真模拟训练。
- **错题诊断归因：** 区分知识盲区、理解偏差与计算失误。
- **答题时间管理：** 训练在限定时间内高效完成试卷。

## 2. 工作流程与执行步骤

1. **出题编制：** 围绕考试大纲编制高质量模拟试卷。
2. **全真闭卷测试：** 严格在无辅助材料、限时条件下答题。
3. **客观标准阅卷：** 对照标准答案精准评分。
4. **错题针对性重修：** 针对薄弱环节开展专项突破。

## 3. 不可逾越的边界与规则

- **客观严肃：** 拒绝盲目给分，保持评分公正严谨。
- **查漏补缺：** 将测试作为诊断工具而非终极评估。
