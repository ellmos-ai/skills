# 学术学习与截止日期管理指南 (中文版)

本技能为高等教育阶段的学习规划、截止日期追踪及考试备考提供系统化支持。

## 1. 概述与目标

- **截止日期与考试管控：** 制定具有约束力的学习与复习时间表。
- **规定合规性：** 对照官方考试大纲与课程指南进行核验。
- **隐私保护：** 严格隔离个人身份信息与学术任务。

## 2. 工作流程与执行步骤

1. **明确目标：** 确定考试日期或论文提交截止点。
2. **评估现状：** 核对考核规定、教学平台与现有进度。
3. **官方在线核验：** 在高校官网上查验最新公告与时间节点。
4. **倒排计划编制：** 从截止日期倒排任务并留出缓冲时间。
5. **输出汇总：** 生成精炼的任务与时间矩阵表。

## 3. 规则与不可逾越的边界

- **官方规定优先：** 出现矛盾时以高校官方发布的规程为准。
- **严禁保存凭据：** 绝不存储账号密码或身份验证码。
- **必须留出缓冲：** 任何计划均须包含防范延误的弹性时间。
