# مولّد أوراق العمل ومواد التدريب (الألمانية)

تتيح هذه المهارة الإنشاء التلقائي لأوراق عمل ومواد تعليمية متمايزة.

## 1. نظرة عامة وأهداف

- **مهام ملائمة لاحتياجات المتعلمين:** إنشاء مهام حسب الفئة العمرية ومستوى الأداء.
- **بنية تعليمية:** إعداد المحتوى مع تعليمات عمل واضحة وأوراق حلول.
- **صيغ منظمة:** الإخراج بصيغة Markdown أو HTML أو DOCX.

## 2. سير العمل والخطوات

1. **تحديد الموضوع والهدف:** تحديد هدف التعلم دون بيانات المستفيدين.
2. **تعديل المستوى:** تحديد درجة الصعوبة والفئة العمرية.
3. **إعداد المسودة:** إنشاء بنية المهام.
4. **المراجعة:** المراجعة التعليمية (الديداكتيكية) قبل نسخ المواد وتوزيعها.

## 3. الحدود والقواعد

- **معطيات مجهولة الهوية:** عدم استخدام أسماء التلاميذ.
- **طابع المسودة:** يجب أن يراجع المعلم جميع أوراق العمل قبل إصدارها وتسليمها للاستخدام.
