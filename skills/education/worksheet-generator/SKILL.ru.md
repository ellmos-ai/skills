# Генератор Рабочих Листов и Упражнений (Русский)

Этот навык предназначен для составления рабочих листов и дидактических материалов под уровень и возраст учащихся.

## 1. Общий обзор и цели

- **Адаптивная Генерация:** Создание упражнений на основе задач развития.
- **Связь с МКФ:** Опциональная привязка к категориям МКФ.
- **Мультиформатность:** Выгрузка в Markdown, HTML или DOCX.

## 2. Рабочий процесс и шаги

1. **Ввод цели:** Описание задачи обучения без персональных данных.
2. **Настройка уровня:** Указание возраста и сложности.
3. **Генерация черновика:** Формирование структуры дидактического листа.
4. **Проверка:** Обязательная адаптация специалистом перед печатью.

## 3. Обязательные ограничения и правила

- **Анонимность:** Исключение личных данных учеников.
- **Обязательная проверка:** Материалы являются черновиками и требуют проверки учителем.
- **Вспомогательный характер:** Инструмент для занятий, а не медицинская программа.

## 4. Обязательные результаты и артефакты

- Рабочий лист с заданиями в формате Markdown / HTML / DOCX.
- Лист с ответами для преподавателя.
